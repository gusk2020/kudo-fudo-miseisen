# Stage 12 — 地形を基盤にした交通・都市経済、都市の栄枯盛衰 (Issue #31 / #30)

目的は「地形 → 都市立地 → 交通手段 → 産業 → 都市圏 → 発展・衰退」の因果が地図の上で見えること。まず Issue #30(山脈を置いても山体の中に交通網と都市が育つ)を再現して直し、その地形評価を都市の経済に接続した。
**新しい仕組みは Stage 12 以降に始めたゲーム(`sim.econ`)だけで動く。** 旧セーブは作られたときの規則のまま動く(§9)。

## 1. Issue #30 の調査(再現 → 原因 → 修正)

再現: 関東に山脈(1本、川越・八王子・さいたまの上)と動かした富士山を置き、1950〜2110年を3シードで回し、毎年の路線を **セル単位で** 障壁と突き合わせた(`tests/study/issue30.test.ts`。辺の分割・付け替えに左右されない、最後に供用中の線がどのセルを覆うか)。

原因(事実):

1. **都市が山体の中に立っていた。** 川越は標高 1,580 m、八王子 1,759 m に入り、山脈なしの世界とほぼ同じ速さで育っていた(人口は平地扱い)。
2. **工費は工期にしか効かず、採択に効かなかった。** 山の工費倍率は上がるが「作る・作らない」には使われない。集落アクセス道は倍率そのものが付いていなかった。
3. **開放線のまま硬い地面を越えられた。** トンネル化は「標高が端点より 600〜800 m 高い最長1区間」だけで、5セル未満の区間は見られず、1区間の上限は約30 km。山脈の高さが「端点より高い」条件に当たらないと、2000 m 級の稜線を地上線が通った。
4. **1950年の初期網にも通行可否の判定がなかった**(経路探索は高額な地面を避けるだけで、避けられないときはそのまま通す)。
5. 空港アクセス線・開通の儀の国道1号は施設(トンネル)化の対象外だった。

修正(`src/sim/land.ts`、規則は全モードで共通):

- **通行可否(ゲート)**: 障壁 × 高さ(`mountainBarrier`)が 5 以上のセルが続く区間は「トンネルでしか越えられない」。その長さがその年の技術の限度(`techAt().tunnelKm`: 1950年 8 km → 1975年 48 km → 2050年 85 km)を超えれば、**高額だからではなく作れない**。新設の道路・鉄道・バイパス・集落アクセス・空港アクセス・1950年の初期網のすべてに同じ判定。
- **採択の資金判定**(`affordable`): 地形で平地より高くなる事業は、費用が地域(鉄道は全国の建設枠)の財布を超えれば採択されない。
- **施設化**(`hardSplit`): 硬い区間は、数に関わらず、長さに関わらず、短くても1つずつトンネルの辺になる。
- **維持費・廃止**: 山の線は維持費が上がり(§2)、赤字ローカル線の廃止基準も同じ倍率で上がる。
- **都市の立地**: §3。

## 2. 地形の費用モデル(非線形)

標高だけの指数ではなく、**開放地・トンネル・山脈の中の施工の別**で足し上げる(`routeBurden`)。経路の工事費倍率 = 1 + (各セルの追加分の合計 ÷ セル数)。

- 開放地: 追加 = `OPEN_K`(0.8) × 硬さ。裾野の切土・盛土・擁壁にあたる。
- トンネル(連続する硬いセル、長さ L km): 追加 = `TUNNEL_UNIT`(道路5・鉄道7) × セル数 × (1 + L/25)^0.8。掘削・換気・安全の費用で、山の高さではなく**長さに対して劣線形でなく優線形**。技術は費用を下げるが、下限(`TUNNEL_COST_FLOOR`)より下がらない。
- 上限・例外: 掘れる最長トンネルを超える線は不採択。川は橋、海峡は Stage 11 の連絡規則。

100 km の経路の工事費倍率(平地に対する倍率。トンネル辺にはさらに施設係数 3 × 1/K):

| 経路 | 道路 | 鉄道 |
| --- | --- | --- |
| 平地 | 1.00 | 1.00 |
| 裾野(開放地・硬さ2) | 2.60 | 2.60 |
| 山脈の足元(開放地・硬さ4) | 4.20 | 4.20 |
| 15 km のトンネル1本 | 2.09 | 2.53 |
| 30 km のトンネル1本 | 3.82 | 4.95 |
| 60 km のトンネル1本 | 8.99 | 12.18 |

掘れる最長トンネル(K=2): 1950年 8 km、1960年 19、1975年 48、1990年 63、2010年 73、2050年 85 km。
維持費の倍率(`upkeepMult`): 開放地は硬さ × 0.12、トンネルは1セルあたり 1.6 を足し、上限 6。100 km のうち 15 km がトンネルなら 1.24、30 km なら 1.48。鉄道の赤字基準(DEFICIT_DENS)も同じ倍率で上がる。

## 3. 都市の立地(地形が都市に効く)

`siteQuality`: 都市の周囲 4 セル(約20 km)の陸地のうち、**平らで(勾配15%以下)・低く(300〜1500 m)・山脈の外**の割合。実在の都市は 0.36(甲府)〜0.97。`SITE_REF`(0.3)より悪い立地だけが「収容力 < 1」になる。実在都市はすべて 1.0(テストで確認)なので、地形をいじっていない世界は何も変わらない。

関東に山脈を置くと: 川越 0.96 → **0.06**、八王子 0.86 → **0.06**、さいたま 0.88 → 0.25、横浜 0.87 → 0.45。収容力は 0.20 / 0.20 / 0.83 / 1.0。

- 開始時: 入れない人は同じ府県の収容力の高い都市へ移る(なければ全国へ比例配分。全国の人口は変わらない: 差 0.2% 未満をテスト)。
- 以後: 混雑の上限が `1950年の人口 × 収容力` で決まる。

結果(3シード平均、千人。1950 / 2000 / 2050 / 2100):

| 都市 | 山脈なし | 山脈あり |
| --- | --- | --- |
| 川越 | 108 / 161 / 109 / 67 | **22 / 20 / 14 / 9** |
| 八王子 | 185 / 297 / 250 / 133 | **36 / 39 / 25 / 15** |
| 横浜(受け皿) | 205 / 334 / 251 / 179 | 356 / 582 / 415 / 198 |

## 4. 都市の経済(`src/sim/econ.ts`)

全国の人口は「1950年の構成での人口動態」に従い(大きさによる増減率の差は都市間の移動に回す。`updatePopulation`)、このモジュールは**どこへ人が移るか**だけを毎年決める。人口加重平均を除いた**ゼロサム**(移動であって創造ではない)。

優位 = 産業 + 物流 + 観光 + 通勤圏 + 集積 − 地価・混雑 − 低地・海面。都市ごとに7つの部分を `sim.city12[id].p` に持ち、地図帳が「なぜ」を言う。

| 部分 | 入力(地名は一切使わない) |
| --- | --- |
| 産業 | 産業水準(土地の平らさ・水・港・アクセス)。重みは(相対値で)1975年に 1.1 でピーク、2030年に 0.3 |
| 物流 | 港の利用率×階級と空港の利用率。重みは貿易の拡大とともに(相対値で)0.3 → 1.4 |
| 観光 | 皇居(文化)・富士・琵琶湖への**陸路の所要時間**。大都市からその拠点へ向かう途中の都市(迂回15%以内)にも波及。国際空港のある都市に入国者の初日。重みは所得とともに増加 |
| 通勤圏 | 首都・副首都が混み合う(収容力の0.9倍超)と、日常通勤できる都市へ住宅が流れる。陸路は所要時間(0.9時間で 1/e)と運賃(所得が上がるほど軽い)。**海路・空路は、扉から扉まで 2.2〜2.4 時間以内で、便数が十分で、天候の定時率(空 93%・海 85%)を掛けた場合だけ日常通勤。週1回しか成り立たない便は四分の一(二拠点生活)** |
| 集積 | 大きさそのもの(収穫逓減) |
| 地価・混雑 | 都市の人口 ÷ 土地が無理なく抱える数。**符号付き**: 縮んだ都市は安くなり、人を引く(衰退の下げ止め) |
| 低地・海面 | 標高10 m未満で海に近い土地の割合 × 年とともに増える重み(2000年 0.1、2040年 0.6、2110年 1.6) |

その他: 局地災害(年 0.6%×、沿岸・悪い立地で増える。3〜8%の減少が15%ずつ戻る)。1都市が国に対して失う・得る勢いには上限下限(`ADV_MIN` −0.55、`ADV_MAX` 1.2): どんなに不利でも故郷の人は残る。
特定の地名を優遇する定数はなく、役割(首都・副首都・皇居)は位置から読む。

## 5. 交通手段の非対称

- 道路・鉄道は沿線に交通が生じる(従来どおり)。**海路・空路は途中の都市に何も生まない**: 空路・海路の流れは陸の辺を使わない(従来どおり)。ただし港・空港・ターミナル・船・飛行機・燃料・人件費は無料ではない: 設備は特別会計(承認判定)で、利用の少ない空港・港・便は休止・廃止される(従来)。
- **天候**(`weatherFactor`): 空は定時率 93%、海は 85%。北や露出した海岸ほど悪く(各端点で緯度 34〜42° に応じて最大 +60% の悪化)、予報と船の大型化で100年かけて3割取り戻す。空路・海路の分担にそのまま掛かる。極端な乱数は使わない。
- 皇居: 文化の拠点として観光を引く。首都と違う場所にあると、その拠点自体と**途中の都市**に観光が生まれる(§7)。

## 8. 未解決・既知の制限

- **全国の人口は完全には一致しない。** 都市の大きさで人口増減率が変わる従来の規則が、人の分布が変わると全国の総数を動かしていた(最初の版では2100年に +4〜+69%)。Stage 12 では全国の増減を「1950年の構成での人口動態」に固定し、大きさによる差は都市間の移動だけに使うよう直した。それでも他の項(アクセス・港など)が分布に反応するため、基準シナリオの2100年は econ なし 26.9/25.2/26.5 M に対し econ あり 31.6/26.4/27.3 M(+17/+5/+3%、2050年は +7/+6/+2%)。
- 東京・大阪の2都市の優位(基準の2100年で全人口の 7 割台)は Stage 11 の規則と同程度に残る。Stage 12 は「その中の動き」と「他の都市の栄枯」を増やしたが、頂点の入れ替えは首都等の置き方を変えた場合に限られる。
- 札幌のような離れた地方の中核は、econ のある世界で 2100 年に 5〜10 万人まで縮む(従来の規則でも 13 万人)。
- 山脈の裾野の広い帯(障壁 > 0.15)の平地には、依然として線が通る。稜線の上は 92〜132 km、トンネル 72 km が残る。
- 通勤の「第2の拠点」(週1回)は住宅の流れの四分の一として入れただけで、別の人口(二拠点居住者)は持たない。
- Issue #30 の視認性(項目10)と地形図での標高重ね(項目12)は未対応。
- 開通の儀の国道1号(物語が贈る道)は1950年の掘削限度に縛られない(トンネル辺にはなる)。
