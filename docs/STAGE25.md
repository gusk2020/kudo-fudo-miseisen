## B 色数の削減と、凡例と地図のスタイル共有
- 線の描き方を **`src/render/style24.ts` の1つの表**に集約。地図(`roads.ts`)も凡例(`legendSamples.ts` → `legend24.ts`)もこの表だけを読む。
- 色: 交通種別ごとに1色(道路 橙・高速 緑・鉄道 紺・新幹線 青・リニア 紫・海路 青緑)と、縁取りの黒・白・灰、強調の1色(マゼンタ。ほかの線には使わない)。
- 傷み具合(良/可/悪/荒廃)は**同じ色の濃さ**(悪いほど淡い)、階層(メイン/サブ/ローカル)は**太さ**、状態は**線種**(供用中=実線、休止=長い破線、計画=短い破線、未成=細かい点、廃線=灰色の破線/点線)。橋は白い帯+黒い縁+横線、トンネルは黒い破線、共用は2本並ぶ。
- 地図の線に使う色リテラル: Stage 24 は **37色** → Stage 25 は **13色**(種別6+黒・白・灰・縁2+比較2+強調1)。
- 対応のテスト: 凡例の各サンプルは、地図が使う `edgeStyle()` の戻り値から作られ、その色・太さ・破線がSVGに入っていることを確認。`roads.ts` の線描画部分に色リテラルが残っていないことをソース走査で確認。E2Eでは実DOMの凡例の線の色が表の色だけであることを確認。
- 比較表示(時系列)の縁取りは5色→2色(良くなった/新規=青、悪くなった=赤)。空路の線は白(薄)→灰に変更(地図と凡例が一致するように)。

## C 150年ごとの遷都イベント
- 2200・2350・2500・2650・2800…。予定年は「何回開いたか」から決まる(`2200 + 150 × 回数`)ので、ずれず、保存・読込でも二重に出ない。高速進行・放置分の計算・タイマー・完全自動/半自動/手動のすべてで、選ぶまで止まる。
- `sim.e2200` は最新の回、過去の回は `sim.e2200hist`(順番どおり)。各回に `n`(0始まり)と `sched`(予定年)。旧セーブ(1回だけ済み)は2350から続く。
- 毎回: 首都・副首都・皇居、交通方針(5)、地域方針(3)、都市配置方針(2)を自由に選べ、「今のまま続ける」は明示の選択。毎回、開始時の49県ルールで順位を引き直し(7%/年のなだらかな移行・人口は動かすだけ)。
- 県庁所在地の新都市のIDは `M<年>-<府県>`(2200は従来の `M22-` のまま)で、同じ府県に何度移しても衝突しない。同じ場所なら新都市は作らない。
- **国道0号**: 2回目以降も「開通の儀」か「見送る」を選ぶ。2回目以降は別の路線(`gen`=年。名前は「国道0号(2350年)」)で、最初の国道0号の番号・辺・履歴には触れない。既存・旧道・廃道を転用する点は従来どおり。路線番号表には載せない(番号を食わない)。
- セーブの上限を、元号 40→400、移転 3→150 に拡大(何度も移すため)。

## D 元号の交互引継ぎと再使用の禁止
- 一度でも採用した元号(通常の改元・遷都の改元とも)は、二度と候補に出ない。新旧字体・全角半角は同じ名前として扱う(`eraKey`)。
- 候補群: 1回目(2200)=1912年の群、2回目(2350)=ゲーム開始時(1945年)の群、3回目以降=2つ前の回に示した群の残り。いずれも「使った名」を毎回除く。
- 残りが3未満になったら5案まで補充: ①日本の実在の過去の元号(大化〜建武。ゲーム未使用) ②それも尽きたら、この世界独自の仮称(画面に「【架空】」と表示。史実ではない)。
- 保存: 各回に示した群・選んだ名・出どころ(`kaigen.reloc[n]`)。採用済みの名は `kaigen.eras` から導く。既存の元号は書き換えない。元号と復興方針は別々に選べる。
