## 1. 1800年の初期道路網
- 原因: `seedInitialNetworkGen` が1800年開始でも1950年式の全国の都市間道路・集落の接続道路を作ってから `seedKaido1800` を実行していた。
- 変更: 1800年開始（`sim.rules1800`）では上記を作らない（`seed.ts`）。作るのは次だけ。
  - 六つの主要街道（東海道・中山道・日光街道・奥州街道・甲州街道・西国街道）と宿場（`kaido1800.ts`、既存）。
  - 街道に乗らない都市は、同じ島で最寄りの接続済み都市が45km以内なら荷車道（番号なし・未舗装・低品質）で結ぶ（`seedLocalAccess1800`）。宿場には短い脇道。
  - 通常の集落には道路ノードを作らない（徒歩・馬・舟の移動は描かれた道ではなくゲーム上のアクセス。`engine.ts` は「ノードのない集落は孤立扱いしない」ので衰退しない）。
- 1950年開始は不変（805区間・152路線をテストで固定）。国道1号の開通の儀は従来どおり。
- 島間接続の需要判定は「各岸の近くに道路か集落」を要件としていたが道路ノードしか見ていなかったので、1800年開始では集落も数える（`islandlink37.ts`）。

## 2. 文明開化列島改造（元号別の技術）
- 提案（暫定採用）: 実験・研究は最大10年、実用化・営業は最大20年早まる。一律30年は使わない。
- 実装（`rules1800.ts`）: 重視方針に合う技術だけ、その元号の下で過ごした年数（`stanceExposure`）に比例して前倒し。20年過ごすと最大。`gateOpen` = `year >= max(開始年, 基準年 − 最大前倒し × min(1, 露出/20))`。
  - 道路重視 → 自動車・高速道路。鉄道重視 → 鉄道（試験・営業・本線の拡大）。空路重視 → 飛行機・飛行船（試験）。均衡 → 動かさない。
  - 海路重視: 船・港・渡船は1800年に既に実用なので動かす関門がない。海路は既存の方針ダイヤル（予算配分）で効く。**関門としては未実装**。
  - 後退しない: 露出は増えるだけなので一度開いた関門は閉じない。後の改元は以後の速度を変えるだけ（テストで 1800〜2050 を走査）。
  - 空港の規則（実年代で書かれている）は `airShiftYears` で同量だけずらす（空路重視で前倒し）。
- 共通判定: 計画・橋トンネル・空港・道路改良の4か所が同じ `mayScheduleServiceFor` / `railMainlineOpen` を使う。年表・地図帳（`history1800.ts` の `reached`、`techNow`）も同じ判定で、行が出る年と実際の解禁が一致する（地図帳の「(○年〜)」は実際に出た年）。
- 架空史の行（開国圧力・維新など）、飛行船の衰退、1950の総合交通は固定。1800年より前へは繰り上げない。
- 飛行船は実験段階のみ（定期運航は実装していない。年表の文言だけを実働と偽らない）。
- 実測（固定シード7・自動）: 鉄道営業が開く年は均衡 1830、鉄道重視の1800年開始ゲームでは1810〜1816（テストで `yr(A) < yr(B)` と 1810 以上を確認）。鉄道延長 km（1830/1860/1900）: 均衡 0/1,343/2,211、道路重視 0/1,124/1,027、鉄道重視 456/631/631。
- 観察（今回の変更とは無関係、未解決）: 鉄道重視の元号は鉄道が早く始まるが、1860年以降の延長が止まる。Stage 39 のコードでも同じ（310km で停止）。方針ダイヤル側の挙動で、別の課題として残す。

## 3. 2000年旧市町村名
- 出典: 国土交通省 国土数値情報 行政区域データ N03 v2.2（2000年10月1日時点, 平成12年）。https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-v2_2.html 。利用許諾: 公共データ利用規約(PDL1.0)。出典: 国土交通省国土数値情報ダウンロードサイト。編集・加工した旨を `note` に記載。
- 取得: `build-gazetteer.yml`（GitHub Actions）が47都道府県のGMLを取得し `tools/build_gazetteer.py` で整形、`src/data/gazetteer2000.json` をコミット（約250KB・ランタイムの通信なし）。ポリゴンは保存しない。保存項目: 標準地域コード・都道府県・名称・郡（政令市の区では親の市）・支庁・代表点（最大の領域の重心。外側なら最長の水平弦の中点）・面積・領域数。
  - 取りこぼしの修正: 初回は件数2,892。`OrientableCurve`（向き付きの参照）を解決できていなかったため。修正後 3,371件（町1,991・市659・村570・区151）。長野120・新潟112・北海道224など2000年10月の県別件数と整合。
  - Geoshape は参照できたが（歴史的行政区域データセット β版）、今回は N03 だけで足りたので取り込まない。
- 利用（`core/gazetteer2000.ts`, `sim/names2000.ts`）: 区（特別区・政令市の区）は候補から外す（名前が衝突し、市の一部のため）。1800年開始の新規ゲームで、集落・宿場・新しい衛星の町に、最寄りの未使用の旧市町村名を付ける（同名は最寄りの1つだけ、距離が同じなら小さいコード）。出典を `Settlement.origin`（コード・名称・県）に記録。旧セーブ・1950年開始は名前を変えない。
- 表示は史実の1800年の行政区分とはしない（2000年時点の地名を元にした架空の1800年。県境は地形から計算する方式のまま）。
- 軽量化: 全件は辞書として持つだけで、活動する集落は従来どおり約190。名前の割り当ては最寄り探索（約3,300件×集落数、1回のみ）。
