# Fix #61: 関門ほかの海峡連絡が都市中心どうしを結ぶ施設になっていた

Issue #61。Draft PR は Stage 40 の PR #62 の上（base `claude/stage40`）。Stage 39 / 40 とはファイルが重ならない（`src/sim/straits.ts` と新規テストだけ）。

## 原因
`straits.ts` の台本の海峡連絡（関門鉄道・関門道路・青函・瀬戸大橋(道路・鉄道)・明石海峡大橋・大鳴門橋・西瀬戸の橋）は、両側の**都市の中心**を端点とする1本の施設区間（トンネルまたは橋）を作っていた。山口市〜北九州市は約83.5km、全区間がトンネル扱いになり、描画・距離・維持費・需要が内陸部まで施設になっていた。

## 修正
施設は海を渡る部分だけにした（`shoreAnchors`）:
- 両都市を結ぶ線から40km以内にある、二つの陸塊の陸地セルの中で、最も近い組を「岸のアンカー」とする（5km格子上で決定的、同距離はセル番号の小さい方）。
- 都市中心→アンカーは、それぞれ**通常の陸上の道路・鉄道**（舗装・施設なし）として敷く。施設区間はアンカー間の2セルだけ。
- 路線は一本（陸上の線＋施設＋陸上の線）として指定する。鉄道の事業者は施設と同じ（引き継ぎ）。
- アンカーが見つからないとき（陸塊が線の近くにない）は従来の都市間施設に戻る（今回の6海峡では起きない）。
- 重複検出（`fixedLink`）は施設の端のセルの陸塊で見つけるので、そのまま働く。再度開かない（`opened`）。古いセーブ（すでに長い施設区間がある）は変えない。

## 限界（正直に）
- 格子は5kmなので、実際の海峡（関門は1km未満）は再現できない。施設の長さは「アンカーの2セル間の距離」で、実在のトンネル長ではない。仮想地理の縮尺の限界。
- 青函25km・西瀬戸26.9kmは格子の都合で長めに出る（実際は青函53.9km、西瀬戸は島々をつなぐ橋）。海を渡る部分だけであることを確認し、距離の上限は30kmとした。
- 監査で見つかった、今回の対象外のもの: ゲームが自分で計画する島間・海峡の連絡（`crossing.ts`/`islandlink37.ts`）は元から岸のペアで作られており、都市中心間ではない（例: 徳島〜神戸 87.6km は**岸と岸の距離**）。陸上の長い橋・トンネル（例: 盛岡1号橋 60km/13セル、熊本2号トンネル 53km/10セル）は地形の関門（Stage 12）の話で別の課題。
