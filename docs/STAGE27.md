# Stage 27

## A 府県境界・青線
- 奈良・和歌山・三重の二重線: 原因は府県ポリゴン(coast-gmj.json)どうしの境が各県で別々に持たれていたこと。`splitGmj` が幾何学的に「海岸」と「県境」を分け、隣接県が共有する境は低い番号の県の1本だけを残す。北海道3区分は例外で従来どおり。
- 宮崎〜大分の青線: 動いていない外洋フェリー(海上の航路)だった。需要のない外洋フェリーは通常画面で描かない(通行量があるか、拡大時に実績があるものだけ描く)。
## B 状態3分類
- 供用中 / 計画・未成 / 廃線・廃道。供用中は種別の基本色・基本線のみ。凡例は地図と同じ見本(`style24.ts` が唯一の定義、`legendSamples.ts` が見本を作る)。新幹線・リニアは凡例1項目。劣化は内部のみ。
## C 生活道路
- `LOCAL_ROAD_ACCESS = 0.05`: 描かれない生活道路による最低限の地域アクセス。都市成長の「アクセス差」に床として入るだけで、人口を生まない(差の平均を引くので総和は保存)。鉄道は全縮尺で全線表示。
## D 150年周期 (src/sim/cycle27.ts)
- 遷都を起点に 復興(0-50) → 平衡(50-100) → 衰退(100-150)。動かすのは3つだけ: 交通予算(BUDGET_POINTS)、人の集まる強さ(GROWTH_BY_PHASE、境で5年かけてなだらかに)、建設意欲(`cycleShape` が道路・鉄道・空路・海路の意欲を底上げ/抑制)。
- 路線ごとの台本はなく、維持費配分・休止/閉鎖/風化・需要復活の既存ルールがそのまま働く。初回遷都前は従来どおり。
- 測定(seed 3/11/29, 2190〜2425, 道路km/鉄道km/休止数): 復興期に道路kmの減少が止まり(例 seed3: 2200→2250で 29086→28781 と横ばい)、鉄道は seed3 で 4640→4833 と増加。衰退期に鉄道が減り(4684→3695)、休止・廃道が増える。
- 限界(正直に): 総人口は既存の人口動態で 14113→1700 まで減り続け、復興期でも増加には転じない。空路は人口の減少に追随して消える。復興の「強い成長」は人の配置と建設に現れるが、総人口の反転ではない。
## E/F 遷都イベント
- イベント中も道路図/地形図を切替可。皇居は移転先の実位置へ(`placePalace`)。自動セーブは遷都イベント完了直後(遷都直前は廃止)、50年区切りと同年なら1件のみ。
