# Stage 2 進捗記録（道路網と歴史シミュレーション）

最終更新: 2026-10-13 / ブランチ `claude/stage2-roads`（base: `claude/stage1-map-generator`、stacked Draft PR。mainへのマージ禁止）

## 完了した機能
1. **データ保護（最優先）**
   - 地図の編集ロック: `finalized` 中は `Store.commit/undo/redo` が拒否される（`onBlocked` で通知）。解除は明示操作のみ（`Store.unlock()`／保存メニュー・各工程のバナー）。道路が存在する場合は解除時に確認し、道路を消す。
   - 地図ハッシュ: `mapStateHash(map)`（seed・各島の変形/配置・琵琶湖/富士山・山脈）。表示設定・工程番号は含まない。道路データは `mapHash` と `terrainHash` を持ち、読み込み時に両方を照合。
   - セーブv2 `{format, schemaVersion:2, map, mapHash, sim}`（`src/core/save2.ts`）。v1（地図のみ、素の状態/旧エクスポート/旧IndexedDBスロット）は自動移行。不一致・破損の道路データは**読み込まず `auto:quarantine` に退避**（部分的な修復はしない）。地図側は従来どおり修復して継続。
   - ロード中に自動保存が道路データを消すバグをE2Eで検出し修正済み（`persist()` は読込待ちの sim も保存）。
2. **開通の儀**（`src/sim/ceremony.ts`）: 1950年（光文6年）開始。酷道1号（東京府起点→陸続きの都市）と腐道1号（東京府内）を指でなぞる。曲線は都市・地形コストの最小経路（描いた線からの距離でコスト増）に吸着。確定前にプレビュー（緑/赤）と不正理由の表示。完了で時計が×1で動き始める。元号『光文』は1926年の昭和代替元号候補を架空史（1945年敗戦時の改元）へ転用する旨をUI明示。政策差は予算+2%のみ。
3. **道路網データ構造**（`src/sim/types.ts`, `network.ts`）: Node（都市/交差点/峠/端点）、Edge（物理区間。路線番号・格付けを持たない）、Route（安定ID＋格付け＋番号＋区間リスト＋履歴。昇格降格で番号が変わってもIDは不変）、Project（計画/工事中/中断/未成線/供用/廃止）を分離。重複指定（1区間に複数路線）、交差点分割（路線・計画の参照を自動書換え）、峠ノード分割に対応。表示名: 国道=酷道、県道=険道、府道=腐道（府は東京・京都・大阪のみ）。番号は(格付け,範囲)ごとに一意で再利用しない。
4. **自動シミュレーション**（`src/sim/engine.ts`）: 月次ティック（整数）。人口・産業は都市ごとの合成値（実在統計ではない。NE人口×0.32を1950年値とし、人口未格納の約15都市は seed 由来の合成）。需要=重力モデル、所要時間・交通量は都市間最短経路から算出。予算（産業×マクロ曲線×政治ムード）→維持費優先→余力で工事。自動延伸（新規計画）、舗装化、供用、昇格・降格、中断（予算不足36か月）→未成線（中断8年）→廃止（30年）、再開、老朽化・風化→廃止→廃道化。全イベントに「原因」文字列を記録（年表で閲覧）。160年実行で 発展(〜2010年代)→衰退 を確認（約0.3秒/百年）。
5. **時間進行**: 停止/×1/×5/×20（×1=実1分で1年）。バックグラウンドでは動かさず、復帰・再起動時に `planCatchUp`（上限30年分、超過分は省略として年表とHUDに明示）を24か月ずつ分割実行。
6. **表示**: 専用の道路レイヤー（`src/render/roads.ts`）。月ごとに地形を再描画しない（変化検出つき）。道路色=品質、破線=建設中/中断/未成線/廃止、番号標識（酷=丸、険=角丸、腐=五角形）、峠マーク。HUD: 年月・速度・路線数・総延長・建設中/未成・状態内訳・最近の出来事。年表・路線一覧シート。レイヤーに 道路/建設計画・未成線/標識。操作ボタンはStage 1の選択表示ルール継承（`aria-pressed`＋✓＋モードラベル）。
7. **風景JSON**: 「風景JSON」ツールで地点をタップ→ `kfm.scenery.v1`（年月・地点・5km格子ID・標高・最寄り道路の状態/路線/舗装/品質/風化・近傍都市）をコピー/保存。5km精度の注記つき。
8. **将来拡張の口**: 道路図鑑・沿道施設・遺構（廃道/未成線の `lost` 区間と Project 履歴）・鉄道/港湾は設計記録のみ（`Edge`/`Project` に交通種別を足す余地、イベントのrefs）。

## 技術判断
- 道路は **5km格子セルの列**が正（vectorはセル列とノード位置から都度生成）。共有区間・交差・分割が単純な整数比較になるため。峠・橋梁・道幅の細部は作らない。
- 路線番号/格付け/物理状態/建設計画を分離（Issue #3の要求）。
- 保存データは道路のみ（地形は保存せず再生成し `terrain.hash` で照合）。端末間で地形が再現しない場合は道路を退避する安全側。

## 既知の問題・限界
- 需要・人口・産業・予算は合成の簡易モデル。調整は `engine.ts` 冒頭の定数。160年で道路は2010年代をピークに衰退し、予算は最終的にほぼ尽きる（極端なシナリオ）。
- 道路は島内のみ（橋・フェリー未対応）。沖縄・北海道は本州と接続しない。
- 腐道は東京府内のみ新規生成の対象にならない場合がある（府の面積が小さいため計画は主に酷道/険道）。
- 他端末（Safari等）での地形再現は未検証（不一致時は道路を退避）。
- 実機(Pixel 7a)確認は未実施。Pages は環境のデプロイ許可ブランチ設定が必要（下記）。

## Issue #5 改修（ブランチ `claude/stage2-road-evolution`）
設計と定量診断は `docs/STAGE2_EVOLUTION_DESIGN.md`。要点:
- 呼称: 正式名称は国道/県道/府道。酷道/険道/腐道は**通称**で、細く荒れた指定道に後から付く（行政指定・規格・物理状態・通称は別データ）。開通の儀は「国道1号」「府道1号」。
- 1950年の既存道路網（合成）: 都市間の最小全域木＋近隣補完、各都市の周りに合成集落、集落⇄都市の生活路。開通の儀の2本は既存網に重ねる（ID・延長の二重計上なし、国道1号/府道1号の番号は予約）。
- 需要を通過/沿線に分離し、規格×路面×品質の速度で最短時間経路に配分。新道（バイパス）が速ければ通過交通が移り、旧道には沿線需要が残る。旧道は `Route.oldEdges` に残し、通過が8年以上激減しても沿線需要(≥25台/日)があれば所管変更（国道→県道/府道）で管理継続、沿線も小さければ指定解除。需要ゼロは明示閾値(4台/日)と年数(5年で休止・12年で閉鎖)で判定し、代替路があり集落が孤立しない場合のみ閉鎖。閉鎖後は風化して廃道。沿線需要が回復すれば復旧(restore)・再開。
- 同時多発: 予算を府県別(均等45%+経済55%)＋全国枠20%、府県ごとの計画キュー(府県を輪番、年12回の経路探索まで)。計画の種類: 集落アクセス/改良/バイパス/舗装化/新規/復旧。
- 見える衰退: 色=品質、太さ=規格、線種=状態、縁色=行政指定、凡例シート、基準年(10年ごとのスナップショット)との比較縁取り、道路タップで「なぜ?」(指定・通称・規格・需要・旧道/新道・永続履歴)。
- 互換: sim スキーマ v2。v1の道路セーブは既定値補完で読み込み（`finishMigration`）。決定論・保存復元の一致をテスト済み。
- テスト: Vitest 68件 / Playwright 15件。
