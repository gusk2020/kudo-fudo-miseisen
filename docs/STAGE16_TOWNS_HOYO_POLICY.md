## 1. 日本海側政策が地図に出なかった原因と対策
測ると統計は動いていたが、**鉄道と高規格道路は両政策でほぼ同じ形**だった。原因は二つ:
- 鉄道網は1950年に全国分が敷設済みで、新線計画は「既存の所要時間が悪い都市対」にしか出ない。日本海側に新線は生まれない。
- 鉄道の「高速化」計画は毎年1〜2件の枠を全国で取り合い、混雑した東海道・山陽の線が毎年その枠を使い切る。政策の加点(RECON_ADD)は新線にしか効かず、既存幹線の格上げには届かなかった。

対策(`recon.ts` の POLICY_* 、`planning.ts`): 政策が優遇する地域(`reconRegionLean ≥ 0.5`)では
- 幹線鉄道を**渋滞の前に**電化・複線化・高速化する(輸送量が容量の5%以上、10km以上)。枠は独立(毎年1件・同時2件まで)。混雑による計画(3.2点〜)には負けない点数 3.3 × fade。
- 幹線道路(2車線、需要が容量の10%以上)を高規格化(点数 2.9 × fade)。

### 東京・関東の優位が残る理由(測定)
関東の人口シェア 30.9%(1955) → 38.5%(2000) → 43.8%(2050) → 45.8%(2100)。Stage 15(町なし)は 29.7 → 38.0 → 40.4 → 44.9。2050年以降の上昇は**全国の人口が半減する(65M→32M)中で関東が最も減りにくい**ため(首都機能・港湾・空港・集積の効果が減少局面でも残る)。東京の「罰則」は置いていない。都市の数が増えた分(関東の町が独立した都市になった)で +1〜3 点出る。未解決として報告する。

## 2. 地方の中小都市(実在の町)
- `src/data/towns.json`: 実在の市町303件(名称・経緯度・概略人口)。市街地として実在する位置のみ。沖縄は除外。
- 地形生成に入れる(ただし地形ハッシュの外、`TerrainResult.towns`)。ゲームごとに首都・副首都の府県とその隣接府県の町を選ぶ(`townsForSeats`: 1府県5件まで、全体40件まで。首都・副首都の県は1.8倍で優先)。
- 旧セーブは町を持たない世界(従来どおり)に接続。新規ゲームは `sim.towns16` に町のidを保存し、読込時は同じ町で世界を作る(`validateSimAgainstWorld` が不一致を退避)。
- 町は都市と同じ人口モデルで動く(1950国勢調査の都市分割・通勤時間・交通費用・鉄道/道路・平野・産業)。国全体の人口は二重計上しない(都道府県の都市人口を都市+町で分割)。
- 金沢首都・大阪副首都の例(シード7): 白山 0.69M→1.25M(2020)、小松 0.67→1.09、姫路 0.38→1.28、砺波 0.30→0.72、南砺 0.31→0.72、尼崎・西宮は増加後に減少。町は一斉には増えず、交通と地形で差が出る。金沢の都市圏の構成市は 6 → 18。
- 衛星の丸: 首都・副首都の都市圏の町は 4万人から丸を出す(従来 15万)。

## 3. 豊予海峡(佐賀関〜佐田岬)
**原因**: 5km格子では佐田岬半島(長さ40km・幅数km)が細すぎて、先端1セルと根元4セルが四国本体から孤立した「点」になり、四国側の道路が先端に届かない。ゲームが認識した九州–四国の最短は延岡付近〜宇和島付近の47km(別の海峡)だった。
**対策**: `world.ts` の `SUBGRID_LAND`(半島の稜線を経緯度で定義)が、世界(地形ではない)の海セルを丘陵地に置き換える。新規ゲームの世界のみ。地形ハッシュ・旧セーブは不変。これで半島は四国本体と連続し、最短海峡は佐賀関セル(131.865E 33.224N)〜佐田岬先端セル(132.031E 33.360N)、セル間21.2km(実際の海峡幅は約14km。5km格子のセル中心間距離)になる。
- 名前: 「豊予海峡(佐賀関〜佐田岬)」(`NAMED_STRAITS`)。フェリー(1950年の既存航路)・計画・開通イベント・地図ラベルがこの名前になる。
- 水底トンネル技術(距離3倍など)は不変。需要・費用・技術の通常の優先順位で計画され、両側の道路網に接続する(両端のノードに道路が付く: 試験で確認)。
- 開通(道路トンネル、既定条件): シード7: 1958〜59年頃、11: 1958年頃、23: 1960年頃(builtMonth 107/106/122)。副首都・首都を石川/北海道にした場合も 1960 年。フェリーは閉鎖。
