# 1800年開始の再設計 — 実装計画(Stage 36以降・案)

仕様は PR #59 のコメント(2026-11-06、`issuecomment-6682261180`)。**このファイルは計画のみ。実装・配備・マージはしていない。** 開始前の監査で分かったこと:

- 開始年 1950 は `src/sim/engine.ts` の `startYear` にあり、1950/150を含む箇所は `src/` 全体で約180。遷都周期は Stage 35 の `startYear + 150·n`(`relocFirstOf`)。
- 「49」を直接書いた箇所は約19、`PREF_IDS` を使うファイルは3。県の追加(樺太県)は、一覧・境界・名前・セーブ検証・ポテンシャル順位(`potential17`の「49県を1回ずつ」)に波及する。
- 沖ノ鳥島・南鳥島は `OFF_GRID`(`src/sim/islands20.ts`)で格子外。選べるようにするには格子上の陸にする必要があり、全国表示の範囲(`updateFitExtra`)にも影響する。
- 小島の初期拡張は `applyG34`(Stage 34)で既にある。皇居が同じ県のときの抜けは 7f1b3e6 で修正済み。
