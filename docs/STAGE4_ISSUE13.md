# Stage 4 再改修（Issue #13）— 実装記録

ブランチ `claude/stage4-issue13`（Draft PR #14、土台は PR #10 の `claude/stage3-foundation`）。main へはマージしない。
**史実／架空／暫定の区別**はこれまでと同じく明示する。

## 1. 地方交通網と道路・鉄道の競争（最優先）
測定先行: `tests/unit/sens.test.ts`（`SENS=1`）が 1950〜2100 を 25 年ごとに計測する（道路/鉄道km、高規格km、地方道路/鉄道km、廃道・廃線km、旅客・貨物の鉄道分担、孤立集落、新設km）。
診断（改修前、平成世界線）: 100 年で地方道路 7,947→3,376km、廃道・廃線 4,388km、孤立集落 0→18（145 中）、地方の新設は集落アクセス道だけ。原因は
(a) 地方路線の新設は都市間 30km 以上・集落アクセス道だけ、(b) 地方鉄道は都市と都市の新線しかない、(c) 集落が鉄道・良い道の恩恵を受けない、(d) 道路と鉄道が互いの充足を見ない、(e) 2000年以降の予算が年3%複利で縮み、2100年には5%まで落ちる。
入れたもの（すべて `empirical`、地名・座標の特例なし）:
- 地方支線: 鉄道が届かない都市／人口1200以上の集落を、最寄りの既設線に短い単線で結ぶ候補（専用枠）。理由に `【地方】` が付く。
- 集落の人口: 鉄道・標準以上の道路が近くにある集落は年+0.7%／+0.5%減りにくい（`LOCAL_RAIL_KEEP` / `LOCAL_ROAD_KEEP`）。つなぐ→残る→需要が出る、の循環。
- 地方道路: 12〜30km の近距離連絡、需要の大きい細道の2車線化、1回の巡回で小さな地方事業を2件目まで許す。
- 競争: 新規道路は「鉄道が既に良い所」で、新規鉄道は「道路が既に良い所」で必要度が下がる（`competeWeight`＝世界線の車/鉄道の好み carBias−railBias に連動、0.25〜0.9）。
- 予算の縮み方を年3%→1.5%に緩和（2027年以降は予測モデル）。
結果（100年、同一seed）: 廃道・廃線 4,388→3,040km、新設鉄道 2,783→3,903km、新設道路 3,049→3,627km、孤立集落率 12%→9%（道路重視では 5%）。

## 2. 限定地形編集（新規ゲームのみ）
- 海岸線・列島の輪郭は現実のまま固定（`bodies` は決して変えない）。首都（東京/京都/大阪＝府の3市）、富士山、琵琶湖、北・南の山脈だけを、**最初の道を引く前**に変えられる。
- `Store.commitLimited/undoLimited/redoLimited`: 確定済みでも通るが、`App.commitEdit` が道路データ（sim）のあるときは拒否する＝開通の儀で固定。Undo/Redo とプレビュー（地形の再生成）あり。
- 山脈は標高の上乗せ（最大3300m）、琵琶湖は内水面（陸地セル=2）としてルート探索に反映。「実際のアルプスの位置」ボタンは飛騨山脈・赤石山脈の尾根のおおよその線（測量値ではない）。
- 首都は `state.capital`／`sim.capital`（都市・行政の設定）。国道1号の起点・府道1号の府、新しい首都の人口×1.35・東京×0.85（架空・暫定）。首都を3市に限るのは「府道」の名が府にだけ付くため。
- 既存セーブ: `capital`/`islands` は設定されたときだけ `mapStateHash` に入るので、以前のセーブのハッシュは変わらない（`709c0b87` を固定して検証）。

地形・府県（兵庫/長崎/新潟/島根）・標高（DEM）・河川・町（洲本・対馬・佐渡・壱岐・隠岐の島町。人口は国勢調査の概数）・集落・1950年の道路まで含む。島番号は5〜9で本土と別（`pathfind` は島をまたがない）。
淡路島は明石海峡大橋・大鳴門橋（史実1998/1985、他の世界線は別年）で本州・四国と結ばれ、他の島は**孤立島のまま**（`isolatedIslands()` で検査）。航路（フェリー）は未実装。`state.islands` が立つ新規ゲームだけ（以前のセーブの地形は変わらない）。

## 4. 改元（1945／1989／2019／将来）
`src/sim/kaigen.ts`。選択は時間を止める（10年政策と同じ仕組み。放置・自動設定では自動選択、保存しても保留が復元される）。
- 1945（最初の元号）: 昭和改元（1926）で実際に挙がった案から選ぶ。宮内省案「神化・元化・神和・同和・継明・順明・明保・寛安・元安」、内閣案「立成・定業・光文・章明・協中」（昭和は除く）。
- 1989: 平成・修文・正化。2019: 令和・英弘・久化・広至・万保。
- 出典（Web検索で確認。一次資料そのものはこの環境から開けなかった）: zatsuneta.com/archives/112252.html、bestcalendar.jp/dates/kinenbi/5130、gendai.media/articles/-/149237・-/152092（昭和）、dic.nicovideo.jp/t/a/平成・xinmin.cn 2019-04-01 PDF（平成）、news.livedoor.com/article/detail/17083568・kanpai-japan.com（令和）。令和の英語記事に「万和」の表記ゆれがあるが「万保」を採用。**候補名は史実、どれが選ばれたかはゲーム。**
- 方針（均衡/道路重視/鉄道重視）の割り当ては**史実ではない**。候補の並びで均衡→道路→鉄道を巡回（名の意味とは無関係）。画面にもそう書く。
- 累積: 世界線の基準ダイヤルは、これまでの元号の方針の加重平均（新しい元号が6年で入り、過去は各段階で×0.5ずつ残る）。民営化は「基準が0.5を超えたとき」に一度だけ。
- 将来（2019以降）: 27〜33年間隔（seedと回数だけから決まる決定論的疑似乱数）。**暫定規則**（`FUTURE_RULES`、定数で変更可）: いろは47字を仮名の字母となった漢字に直し（「ぬ」＝奴は不適切なので「縫」）、改元年の十干または十二支1字と組み合わせ、2字語を画数の和が少ない順に5案。禁字表・禁語・実在/既出の元号・同回の重複を除外。
- 旧形式のセーブ（`kaigen` なし）は従来どおり単一元号で改元しない。形式不正の `kaigen` は捨てて単一元号として続行（セーブを拒否しない）。

## 5. 橋梁・トンネル技術（道路・鉄道共通）`src/sim/tech.ts`
K=2（`TECH_K`、暫定）。**重複適用を避ける設計**: 到達距離・難岩盤の成功率は「技術の時計」`1950+K×(年−1950)` から読む（ここだけが倍化の入口。成功率は1で頭打ち、長さは曲線の天井）。建設費・工期はトンネル/橋の部分にだけ1/Kを1回掛ける。モードを見る箇所はない。
- 到達距離を超えるトンネルの計画は「まだ作れない」で見送り、同時に進むトンネル計画は3件まで（採択の集中を抑制）。難岩盤は成功率に応じて工費+35%。
- 渡りやすさ（`crossingEase`）で山・川の探索コストが下がり、より直線的な経路が選ばれる。
- `sim.tech` があるのは新規ゲームだけ。以前のセーブは従来の固定ルール。

## 定量比較（1950〜2100、`tests/unit/quant.test.ts` / `SENS=1`）
世界線（元号の選択）と10年政策を**別々に**変えて比較（指標8種×2000/2050/2100年の平均変動幅 = (最大−最小)/平均）。
| 変えたもの | 平均変動幅 |
| --- | --- |
| 元号の道筋（均衡・道路重視・鉄道重視の3通り、全改元で同じ方針） | **0.58** |
| 10年政策（なし・政治・経済、世界線は固定） | 0.12 |
| 最初の元号だけ | 0.25 |
| 1989年の選択だけ | 0.15 |
| 2019年の選択だけ | 0.10 |
| 2049年前後の選択だけ | 0.04 |
| 10年政策（4通り、別計測） | 0.17 |
一回の選択は後ほど短い期間にしか効かないので小さいが、道筋全体では政策の約4.6倍。ユーザーの「元号の影響より政策が強すぎる」は、改修前の測定（元号0.56、政策0.13）では数値上は再現しなかった。体感との差は、元号の影響が年単位でゆっくり現れ、政策の窓は画面で止まって見える点にあると考えられる。今回は元号を累積させたので、遊び方によらず残る。
2100年の例（道筋別）: 道路重視 道路10,008km・鉄道4,002km・高規格4,564km・鉄道旅客分担34%／鉄道重視 道路8,972km・鉄道8,271km・高規格1,199km・分担94%／均衡 9,822・6,348・3,631km・55%。
