# 1800年開始の人口・地形の扱い(Stage 36)

値の種類を次の4つに分けて記録する。史実値と推計を混ぜて「史実」と呼ばない。

| 種類 | 内容 | 現在の使用箇所 |
| --- | --- | --- |
| 史実値 | 1792年 29,869.7千人、1846年 32,297.2千人(江戸幕府の人口調査として知られる全国値) | `rules1800.ts` の基準点 |
| 補間値 | 上の2点を直線で結んだ1800年 ≒ 30,229千人 | `POP_1800_TOTAL_K` |
| ゲーム用推計 | 1950年の都市人口に比 `POP_1800_FACTOR`(≒0.363)を一律に掛ける。最小500人 | `engine.ts` 開始時 |
| 架空史補正 | なし(人口に架空の補正は入れていない) | — |

## 限界(明記)
- 都市・県ごとの1800年の実数は入っていない。**都市の大小関係は1950年のまま**(江戸・大坂・京都の相対的な大きさなどは再現していない)。
- 令制国別の人口表は未入手。入手でき次第、都市別の「史実値/補間値」列を足し、推計行を置き換える。入手待ちで開発は止めない。
- 画面では「ゲーム用推計」と読める注記を付ける方針(未実装なら残課題)。

## 地形
- 標高は現在の暫定地形を維持する。南樺太・千島は暫定形状で、出典のない標高を実測値とは呼ばない。
- GEBCO等の実測データへの差し替えは別課題。
