# Stage 7 — 交通シミュレーションの改善(定量分析にもとづく)

## 1. 分析の方法
- `tests/study/study.test.ts`(通常のテストには含まれない)で 1950〜2100 年を条件を変えて実行し、10年ごとの指標を JSON に出す。
  - 実行: `STUDY=1 SCEN=H-auto,S-auto OUT=/tmp/study npx vitest run`
  - 要約: `python3 tools/study_summary.py <dir>`、改修前後の比較: `python3 tools/study_compare.py <before> <after>`
- 条件(18通り): 最初の元号の方針(H=均衡 S=道路 R=鉄道 A=空路 K=海路、以後の改元も同じ方針)/ 1989・2019 年に実名の第1候補(平成・令和=均衡)を選ぶ場合(`*-later1`)/ 政策介入(自動・なし・道路重点・鉄道重点)/ 首都(沖縄+札幌、大阪+東京)/ 島なし / 別シード。
- 指標: 道路・鉄道の延長(規格別、国鉄/私鉄)、旅客・貨物の鉄道分担(人km・トンkm相当)、廃線・廃道の延長、バイパス・未成線、計画の開通・中止・凍結・未成化の件数、人口、最大の1か月処理時間。計測時に行う需要計算は結果を元に戻すので、計測が結果を変えることはない。

## 2. 改修前に分かったこと(原因)
| 症状 | 計測値(改修前) | 原因 |
|---|---|---|
| 道路と鉄道の競争が路線網に表れない | 道路重視(S)と鉄道重視(R)で旅客の鉄道分担は 0.07 対 0.75 と大差なのに、1990年の鉄道延長は 5609 対 6068 km とほぼ同じ。廃線は R の方が多い | 集落の利用者が自動車と分担されず、鉄道の沿線需要は自動車社会でも一定。廃線は「利用ゼロ」か「保守費不足で荒廃」の場合だけで、赤字を理由に事業者が手放す仕組みがなかった |
| 地方の交通網が発展しない | 150年間で道路新設 約20件、集落道 約10件 | 新道の候補の9割(604件中543件)が「既存道路をなぞる経路になり新設区間が短い」として捨てられていた。改良と新設が同じ順位表で競い、混雑区間の改良が常に勝っていた |
| 資金があるのに建設が進まない | 国の予算枠の96%、府県の予算の63%が毎月使われずに消えていた | 計画の受け入れ数(府県あたり同時2件・3.5年に1度の巡回)が上限になっていた |
| 元号の選択より政策介入が効く | 最初に道路重視を選び、1989・2019年に第1候補(平成・令和)を選ぶと、2050年の鉄道分担は 0.26 で均衡(0.24)とほぼ同じ | 改元のたびに前の元号の重みを半分にしていたため、2回の改元で最初の選択の 3/4 が消えていた |

## 3. 改修内容
1. **集落の利用を鉄道と自動車で分担**(`demand.ts` `localRailFactor`): 都市間と同じ自動車/鉄道の選好で配分(1950年頃 1.3倍 → 自動車社会 0.15倍、0 にはならない)。
2. **赤字ローカル線の廃止**(`railecon.ts`): 輸送密度 2,500 人/日未満の赤字が続く路線を事業者が廃止(私鉄・三セクは6年、国鉄は10年かつ 1,500 人/日未満で補助が薄いとき)。鉄道重視の世界線や補助の厚い時期は守られる(私鉄は基準が半分)。年3路線まで、高速幹線は対象外、混んでいる共用区間は残す。理由と数値を履歴に記録。
3. **道路網の新設**(`planning.ts`): 改良と新設を別枠で選ぶ。既に結ばれた2都市は、大きく短絡できるなら峠道・トンネルの新道、そうでなければ経路上で最も遅い区間を改良/舗装。人口 1,200 人以上の集落には、隣の集落への道が遠回りなら**地方道**(人口が減れば休止・廃道へ)。
4. **国庫補助と予算の余り**(`engine.ts`): 府県が賄えない月の不足分を、国の予算枠の余りから半分まで補助(優先度3以上)。予算が余っている府県は同時に3〜4件まで計画できる(`regionSlack`、セーブに保存)。
5. **工事凍結と再開**(`freeze.ts`): 建設意欲が一定以下に落ちた年、1年で12%以上落ちた年(政策・改元)、国鉄改革の年、道路の財政引き締めの年に、優先度の低い未完成の新線・バイパスを凍結。意欲が戻れば再開、戻らなければ8年で未成線。
6. **元号の方針の蓄積**(`kaigen.ts` `eraWeights`): 各元号を「続いた年数」で重み付け(現在の元号は2倍)。44年続いた最初の元号は2100年にも約2割残る。
7. **政策介入の上限**(`eras.ts` `POLICY_CAP`): 同時に効いている政策の合計で、1つのダイヤルを範囲の12%までしか動かせない(事件は対象外)。政策は世界線の中で舵を切るが、世界線を置き換えない。
8. **私鉄の参入**: 国鉄時代でも、人口15万以上・130km以内の都市間は私鉄が建設できる(以前は25万・110km)。
9. **発展の歯止め**: 1950年の規模の3倍(平野が広ければ最大8倍)を超えた都市は成長が鈍る(土地・水・住宅)。交通→発展→需要の正のフィードバックが無限に続かない。今回の条件では最大2.6倍で、まだ効いていない(安全弁)。
10. **性能**: 毎月の処理(維持・建設・鉄道)と年次の区間評価を小分けにして実行。

- **競争が路線網に出るようになった**: 1990年の鉄道延長は S 4,134 / R 5,913 km(以前は 5,609 / 6,068)。赤字ローカル線の廃止は 2050 年までに S 22路線、H 12、R 2。
- **元号の方針が残る**: 道路重視で始めて以後は平成・令和を選んだ場合、2050年の鉄道分担は 0.20(均衡 0.28 より明確に低い。以前は 0.26 で均衡と区別がつかなかった)。鉄道重視なら 0.45。
- **政策の効き目は世界線より小さい**: 2050年の差(最大−最小)は、元号の違いで鉄道延長 4,320 km・鉄道分担 0.64、政策の違いで 108 km・0.07。ただし廃線の量には政策が効く(1,240 km)。
- **地方の網**: 地方道・集落道の開通 10→34件、バイパス 83→96件、鉄道新線 37→48件(H)。
- **未成線**は 35→11件(H)に減った。主に、使われずに消えていた国の予算を府県の工事に回したため。未成線は「工事凍結(H で27件、うち再開されなかった分)」と、補助対象外の小規模工事の中断から生まれる。必要なら凍結の感度で増やせる(次の課題)。

## 6. セーブの互換
- 追加した項目(`regionSlack`、路線の `deficitYears`)は省略可能。古いセーブは読み込み後に自動で作られる。不正な値は読み込み時に捨てる。
- 地図ハッシュ・地形ハッシュは変わらない。ラウンドトリップ後も同じ結果になることを単体テストで確認。

## 7. UI(Issue #20 の残課題)
- 地形編集を開いている間は、ツールバーを編集専用の1行にした: [✕ 地形][琵琶湖][富士山][山脈][↶][↷]。琵琶湖・富士山を選ぶと回転・大きさの行、「山脈」で北/南/点/実アルプス/消去の行が出る。元号・首都・国道1号の行は編集中は隠す。
- ツールバーの高さ(Pixel 7 幅): 編集を開いた状態 **286 → 42 px**、富士山を選択中 **352 → 80 px**、山脈の行を開いた状態 118 px。
- Undo/Redo、ピンチ・回転、再タップでの解除、配置検証はそのまま(E2E で確認)。

## 8. 交通の移り変わり(地図帳)
- 地図帳シートの下に、道路・鉄道の延長と、鉄道の分担(旅客・貨物・空路)の折れ線グラフ、最近の転機(赤字線廃止・工事凍結/再開・国鉄改革・開業など)を表示。毎年の記録(`sim.stats`、旅客・貨物の分担を追加)から描くだけで、シミュレーションには影響しない。古いセーブでは分担のグラフは記録が溜まってから出る。
