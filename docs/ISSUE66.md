# Issue #66: 鉄道重視の停滞（A）と海路重視の技術発展（B）

branch `claude/issue66-rail`（base `claude/stage40` = PR #62。PR #63 とは独立）。

## A. 鉄道重視で鉄道延長が止まる — 原因を特定して修正
### 調査（1800年開始・自動、固定シード7、`planRailGen` の関門ごとの計測）
- 年ごとの候補数は鉄道重視でも均衡でも十分あった（新線の候補 5件以上が全ての年）。方針ダイヤル `railBuild` の低下（1.00→0.06、経済循環）は両方に同じに起きており、差の原因ではなかった。
- **鉄道重視だけ**に、技術の関門（`techCheck`: その年の技術で掘れないトンネル長が要る山越え）の失敗が毎年 3〜4件（1830〜1890年に合計 21/64/80/80/49 件）。均衡は 0件。
- 計画は1年に経路探索を `MAX_RAIL_PATHFINDS = 5` 回しか試せない。上位に並ぶ、技術的にまだ建設できない同じ区間が毎年その枠を使い切り、建設できる下位の候補に順番が回らなかった（飢餓）。
### 修正
- 技術の関門に落ちた新線の候補（キー: 都市の組・セル）は、`RAIL_RETRY_YEARS = 6` 年は試さない（`sim.railFail` に年を記録）。技術が進めば再び試される。1800年開始ゲームだけ（`sim.rules1800`）。1950年開始は従来どおり（`railFail` は作られない。テスト済み）。
- 倍率・建設量の保証・方針の補正は入れていない。停止（需要・予算・地形・技術）は従来どおり。
### 結果（鉄道延長 km、修正前→修正後。1830 / 1860 / 1900）

- 1860→1900 の伸び: 鉄道重視は +0〜+15 km → +365〜+1028 km（シード7・11・23）。1830年には鉄道重視が鉄道を最も早く持つ（626〜730 km、均衡は 0）。1900年に均衡を上回るのはシード7・11で、シード23は 2053 対 2172 とわずかに下回る（「必ず上回る」とは言えない）。
- 残る観察: 道路重視（シード7）は 1950年に鉄道延長が最大（4472 km、鉄道重視 3418）。方針の効果は鉄道延長に関して単調でない。方針ダイヤルが1950年以前は1950年の値で平ら（`eras.ts` の PROFILE）なことが一因と思われる。未解決。
- 副次: `c37` の「遠北（樺太・千島）への島間接続」は、Stage 40 で最大30年遅れて 2030年での確認にしていたが、鉄道の修正後は 1995年に成立する（Stage 39 と同じ時期）。確認年を元の 2000年に戻した。

## B. 海路重視の技術発展
- 船・港・渡船は1800年から実用（帆船）。これは関門にしない。
- 追加した段階（架空の未発明技術ではなく、船の更新）: 1830年基準の**蒸気船の定期航路**（渡船の速さ ×1.35）、1880年基準の**鋼鉄の汽船**（×1.8）。`rules1800.ts` の `shipGrade`。
- 海路重視の元号（`kairo`）の下で過ごした年数に比例して最大20年早まる（Stage 40 の方式と同じ。露出20年で最大、単調、開始年より前にならない、他の方針では動かない）。均衡でも基準年に開く。
- 実際の影響: `demand.ts` の `edgeSpeed` が渡船の速さを段階で変える（辺の `shipGrade`、1800年開始で毎年更新）。移動時間→需要・経路・計画の判断に効く。年表・地図帳には「船舶」の行として出る（実際に開いた年）。
- 完成済みの施設・技術は後の改元で戻らない（テストで 1800〜2050 を走査）。1950年開始は影響を受けない（`shipGrade` は付かない）。
- 未実装（正直に）: 港の取扱量の段階・運河・河川航行。港の容量（`hubs.ts`）は動かしていない。Stage 41 の海路世界の条件も扱っていない。
