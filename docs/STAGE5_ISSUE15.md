# Stage 5 追加改修（Issue #15）— 実装記録

ブランチ `claude/stage5-issue15`（Draft PR、土台は PR #14 の `claude/stage4-issue13`）。main へはマージしない。

## 1. 改元・世界線: 空路重視・海路重視
- 政策の方針（stance）は 均衡 / 道路重視 / 鉄道重視 に **空路重視（`kuuro`）・海路重視（`kairo`）** を加えた5つ。`Dials` に `airBias`・`seaBias` を追加（既定0＝従来どおり）。
- 空路: 空港の開港が早まり（`airBias`×8年）、長距離の航空分担が大きくなる。海路: 港湾の貨物分担が大きく、海峡連絡で橋・トンネルより船を長く使う（`seaBias`で構想の意欲が下がる）。**運航の詳細モデルは未実装**（政策データと拡張点だけ）。
- **元号と方針の対応表**は `src/sim/kaigen.ts` の一箇所（`eraTable()`、テストで固定）:
  - 1945（1926年の落選案14案）: 神化=均衡／元化=道路／神和=鉄道／同和=空路／継明=海路／順明=均衡／明保=道路／寛安=鉄道／元安=空路／立成=海路／定業=均衡／光文=道路／章明=鉄道／協中=空路
  - 1989: 平成=均衡／修文=道路／正化=鉄道（実在候補は3つだけなので、空路・海路は無い。名前を水増ししない）
  - 2019: 令和=均衡／英弘=道路／久化=鉄道／広至=空路／万保=海路
  - 将来（暫定規則で生成）: 候補の並びで5つを巡回。
  - **割り当ては史実ではない**（候補の並び順に巡回。名前の意味とは無関係）。候補名は史実、方針はゲーム上の仮。画面にもそう書いてある。
- 空路・海路の方針は、均衡の史実表（事件・海峡の年）を「架空」と明記して読む。既存の保存済み世界線・1989/2019の改元履歴とは互換（保存値は従来の3つのまま読める）。

## 2. 首都・副首都・皇居
- 3つは独立した設定。どれも **49府県すべて**（北海道3県・沖縄を含む）から選べる（`src/core/seat.ts`）。首都と副首都は別の府県（UIで選べない／拒否）。皇居は首都・副首都と同じ府県でもよい。
- 県内の代表地点は県庁所在地。皇居は地図をタップして県内の陸地に置ける（県外・海は拒否）。地図に 首都（赤い星）・副首都（青い星）・皇居（金のひし形）を常時表示。
- 保存・復元: `capital` / `subCapital` / `palace` / `palacePos`（設定したときだけ地図の照合値に入るので、以前のセーブは不変）。以前のセーブが持つ都市ID（`C-JP-27`）も読める。
- 皇居は首都に自動連動しない。将来の政治・需要効果の拡張点は `PALACE_LINKS`（空）。

## 3. 国道1号と海峡連絡
- 開通の儀で描くのは **国道1号のみ**（首都→副首都）。府道1号の描画・ボタンは廃止。複数ストローク・自動接続補正・Undo/Redoは維持。
- 陸地の塊（`World.lm`）ごとに経路を作り、海をまたぐ所は **フェリー航路を自動で挟む**（沖縄→九州→本州→北海道のように連鎖）。プレビューは陸地を実線、航路を青の破線で表示。
- フェリーは道路ではなく別種の辺（`facility: "ferry"`）。舗装・劣化・維持費がなく、地図でも道路の縁取りを付けず航路として描く。新しいゲームは開始時に全ての陸塊を航路で結んでおく（`seedFerries`）。
- 沖縄・北海道・四国・九州・離島を首都／副首都にしても経路が成立することをユニットテストとE2E（那覇→札幌）で検証。

## 4. 橋・トンネル・フェリーの選択（道路・鉄道とも）`src/sim/crossing.ts`
- 毎年、航路ごとに: 技術（橋の支間 / トンネルの長さ。`BRIDGE_KM`・`TUNNEL_KM`を技術の時計K=2で読む）→ 需要（航路の混雑）→ 意欲（hwyBuild/railBuild/hsr、海路重視で低下）→ 費用（国の予算から賄えるか）→ 人口（小さい側の人口が海峡1kmあたり3,500人以上）。条件を満たす最も安い構造を選ぶ。足りなければ航路のまま。
- 上限: 1モードにつき同時に1件、同じ組は12年あけて再検討。航路が橋・トンネルに替わると、航路を廃止し、国道などの路線を新しい連絡へ付け替える（同じ港の組）。
- 履歴は通常の計画と同じ（構想・計画・工事中・中断・未成・供用・取りやめ）。年表に `海峡…構想` `海峡連絡が開通` `…を廃止` が残る。
- 技術加速ルール（K=2、費用・工期1/2を1回だけ、成功確率は1で頭打ち）は維持。
- 1950年に橋は強制しない（フェリーで接続）。K=2はK=1より遅くならない。

## 5. 地形編集の追加
- 琵琶湖の拡大縮小（0.5〜2倍）、富士山の山体の拡大縮小（0.5〜2倍）と高さ（0.5〜1.3倍）。位置・回転とは独立して Undo/Redo、プレビュー（地形の再生成）、保存・復元に対応。湖が海岸に触れる拡大は拒否（`validate`）。海岸線・列島の輪郭は固定のまま。アルプス・首都（府県）の編集は維持。

## 6. 政策介入画面
- 「政治」「経済」「世論」と並んで **「選択しない」** を最初から表示（分野を押す前から）。分野を選ぶと **「この選択にする」** が分野の行のすぐ下に出る。選択しない場合は何も採用せず、持ち点は全額繰り越し、時間は再開。履歴にも記録。

## 7. 凡例の路線名
- 番号標識（数字のみ）と路線名の文字を分離。名称表示OFFなら全路線で数字だけ。ONなら国道・府県道・鉄道・途中で指定された路線すべてに名称（例: 国道1号、旧国鉄◯号線）。描画のたびに設定を読み直すので、ズーム・年代スライダー・再読み込みで一致。ラベルは使い回し（描画メモリの増加なし）。
