## 2. 見つけた事実（次に効く）
- 遷都のたびに国道0号が作られ、2本目以降は `gen`（年）で区別される（`ceremony.ts`）。`numreg.ts` は `gen` の路線を番号台帳から除く。**特殊路線の新仕様（§6）はここを作り替える**ので、`gen` の扱いを壊さないこと。
- 旧版の地形は新版と**完全一致しない**。旧保存の復元を後から作るなら、生成処理を版で分ける設計が要る（`SAVE41.md` の「採らなかった案」）。
- `advance()`（テスト・ツール用の早送り）は開いた政策の窓を自分で解決する。アプリの時計は解決しない。時間が止まることをテストするときは `stepMonth` を直接呼ぶこと。
- 自動モードでは遷都（`unattended`）は**イベントを開かず飛ばす**（`skip2200`）。判断直前のセーブはその直前に `open2200` を写しに適用して作る。
- 既存E2Eは**遅い**（CI で全体 約45〜80分。`real.spec.ts` だけで約20〜30分）。ローカルの Chromium は `/opt/pw-browsers`（`CHROMIUM_PATH=$(ls -d /opt/pw-browsers/chromium-*/chrome-linux*/chrome)`）。PlaywrightのスクリーンショットはCI（ソフトウェア描画）で20秒を超えて失敗することがある: E2E に記録用のスクリーンショットを入れない。
- **コードやテストの行の途中に `// コメント` を足さない。** 同じ行の後ろにある処理が丸ごと無効になる。今回、上部の表示（路線数・建設中のピル）と、E2E の確認と「閉じる」操作を、これで一度ずつ消してしまい、E2E が捕まえた（`app.spec.ts` と `techui37.spec.ts`）。コメントは行末か別の行に書き、機械で確かめるなら「`)   // ...` の後ろに文が続く行」を検索する。
- 交通グラフのボタン（`#led-graph`）は**押すたびに入り切りする**。E2E では `aria-pressed` を見て、切れているときだけ押す。
- 時刻の扱い: 状態行の時刻は `TZ=Asia/Tokyo date` の値だけを使う。**推定の時刻を書かない**（この会話で一度やって訂正した）。
- 浅い clone では `git push` が「未pushのコミットがある」とフックに言われることがある（リモート追跡の設定が無いため）。`git fetch --depth=1 origin <枝>` と `git branch --set-upstream-to` で直る。

## 6. 特殊路線（#8）の設計メモ（新仕様が最優先。旧案「1→0→阿→A→甲…」は破棄）
- 順序: 1号（イチ）→0号（ゼロ）→A号（エー）→元号（ゲン）→始号（シ）→ㄅ号（ボ）→ᚠ号（フェ）→Ⰰ号（アズ）→ꀀ号（イ）→᚛号（ベイ）→𓃀号（ベー）→⌘号（コマ）→ꙮ号（オク）。**建設順で決まり、暦年では飛ばさない**（見送ったら次回は未使用の次の記号）。前の特殊路線が完成していることが、次の特殊路線を作る条件。
- 通過条件: 首都と副首都がある場合は両方を通る。皇居は近くを通れば通過とみなす。始点・終点は固定しない。寄り道・環状を認める。**路線全体が一筆書き可能**であること（グラフとして検証: 連結で、奇数次数の頂点が0個（環状）または2個。同じ交差点を通る場合を含める。単に始点・終点を見るのではなく路線全体の接続を見る）。
- 既存の特殊路線の延長も選べる（番号維持、延長後も一筆書き可能、環状化可、無関係な枝は不可）。
- 識別: 通常路線（数字）と特殊路線は内部IDでも区別する。表示（標識・地図・路線帳・年表・保存表示）は同じ記号。Pixel 7a で表示欠け・豆腐になる字（ᚠ Ⰰ ꀀ ᚛ 𓃀 ꙮ など）が出るので、SVG／フォールバック描画を用意し、**意味と内部IDは表示フォントに依存させない**。フォントのライセンスを確認し、外部サービスへの依存を増やさない。
- 現状との接点: `ceremony.ts`（`performNational` ＝1号、`performRoad0` ＝0号、`designate`）、`numreg.ts`、`engine.ts routeOfficial`、`event2200.ts`、`network.ts checkIntegrity`（`gen`）、`save2.ts`。旧式の国道0号を持つ保存の移行（`repairRoad0Years`）と整合させる。
