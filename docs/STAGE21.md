# Stage 21: 府県リスト・タブ・国道1号の双方向と沿道の県庁所在地

## 設定欄
- **府県リスト**: 首都・副首都・皇居のタブを押すと、すぐ黒背景・白文字の窓(`#pref-picker`)が開く。地方ブロック(北海道〜沖縄)ごとに府県ボタン(3列、県庁所在地名つき)。下に「地図で選ぶ」「戻る」。選択中は青、首都⇄副首都で重複する府県は選べない。中間の「A 府県から/B 地図から」は廃止。
- **地図選択**: 「地図で選ぶ」で窓を閉じて地点指定。「決定」「取り消し」「戻る」。取り消し・戻るは設定を変えない(戻る = 府県リストへ)。決定時は Stage 20 のとおり、その点がその府県の県庁所在地になる。
- **タブ**: 首都/副首都/皇居/元号のタブを地形・琵琶湖・富士山と同じ小さな寸法(高さ34px、文字12.5px)に統一。押されたタブは青。
- 府県リストの「戻る」は窓だけを閉じ、タブの欄(現在の設定と「選び直す」)に戻る。

## 国道1号
- **双方向**: 副首都側から描いても同じ道。端点の判定が首都側・副首都側の入れ替えを許すとき、線を向き直して扱う(`NatPreview.reversed`)。
- **端点の許容**: `snapKmFor(zoom)` = 指先(24px)の地理距離を 30〜90km に収めた値。30kmは5kmグリッドでの6セル(これより近い点は区別できない)、90kmを超えるともうその都市に向けた線ではない。端点と都市の間は常に陸の最短路(または自動のフェリー)で結ぶ。海の上の直線では結ばない。許容範囲外は従来どおり理由つきで拒否。
- **沿道の県庁所在地**: 線から20km以内の県庁所在地は、(1)寄り道が15km以内なら経由地として線を通す(`through`)、(2)そうでなければ陸路の取付路を、距離30km以内・直線距離の1.7倍+8km以内・山の壁(`mountainCost`)1.8以下・全て陸のときだけ作る(`spurs`)。島は道では結ばない(陸塊が違えば対象外)。同じ都市に取付路は1本。開通時に既に開いた道路上にある都市には作らない。
