# Stage 34: 島の拡大と埋め立て

実装: `src/sim/reclaim34.ts`(新規)、`world.ts`(`buildWorld` の第6引数 `g34`、`worldMemo`/`resetWorldCaches`)、`engine.ts`(年1回 `stepReclaim`)、`ui/app.ts`、`render/renderer.ts`(追加した陸地を砂色のマスで描画)、`core/save2.ts`(保存検証)。

## 格子と実効面積(重要)
- 地図は5km格子で、1マス＝25km²。30km²や年5km²は地形に直接は出せないため、**内部の予算(km²)と地形のマスを別管理**する。
- 予算は0.5km²単位の整数(浮動小数点の誤差なし)。5km²/年＝10単位、0.5km²/年＝1単位、1マス＝50単位。**予算が1マス分(25km²)になった時点で1マスだけ陸地にする**。毎年1マス足すことはしない。
- 島の拡大: 目標30km²だが格子は25か50しか表せないため、**1マスの島(25km²)は2マス(50km²)になる**。実効面積は常に報告する(2マス以上の島は元から50km²以上なので変更なし)。誤差: 目標より最大+20km²(+67%)。
- 埋め立て: 100年で最大 250+25＝275km²＝**11マス**(実効275km²、誤差なし。250は10マス、25は1マスちょうど)。

## 規則
1. **島の拡大**: 首都・副首都・皇居の各座席について、世界を作る時(開始時・遷都後の作り直し時)に、その座席のマスを含む陸塊(同じ島番号の8近傍連結)が30km²未満なら、座席に近い順に4近傍で接する海のマスを足す。皇居も対象(皇居は埋め立てなし)。
2. **陸続きにしない**: 足すマスは、その8近傍の陸がすべて「育てる陸塊」のものである場合に限る(辺でも斜めでも他の陸塊に触れない)。湖(land=2)・海以外には足さない。足す余地がなければ拡大しない(予算は保持)。
3. **埋め立て(首都・副首都のみ、それぞれ独立)**: 座席の2マス以内に海がある場合のみ。座席ごとに開始年から数えて1〜50年目は年5km²、51〜100年目は年0.5km²、101年目以降は停止。座席から8マス(40km)以内で、育てる陸塊に辺で接する海のマスのうち座席に最も近いものを足す(同距離は番号の小さい方)。
4. **二重計上なし**: 足したマスは陸になるため、別の座席が同じマスを足すことはない。そのマスを足した座席だけが予算を払う(他の座席の予算は使わない)。
5. **合法なマスがない場合**: 予算は消費せず保持し、翌年また試す(`blocked` に回数を記録)。
6. **遷都**: 座席が変わると旧座席の埋め立てを止め(陸地はそのまま残る)、新座席の予算を0から開始する。島の拡大は世界の作り直し時に新座席へ適用される。*自動運転での遷都スキップ(Stage 35)は未実装*。
7. **保存・復元**: 陸地に起きた変更は順序付きログ(`sim.rec34.log`)に残る。世界は「地形＋ログ」から再構築されるので同じログなら同じ陸地になる。ログに無い座席だけが新たに拡大される(`done` に判定済み座席のキー)。予算・経過年・埋めたマス数は `sim.rec34.sites`。保存検証(`validateSimAgainstWorld`)がログと地形の一致を確認する。
8. **更新**: 陸地が変わるたび、`World` をキーにした全メモ(海峡・フェリー・航路・港湾・都市の用地など)を `resetWorldCaches` で破棄し、橋・トンネル・航路の判定を再計算させる。陸塊番号 `lm` は足したマスにも同じ番号を与える(別の島とは決して統合されない)。

## 旧セーブ・既存機能
- `rec34` を持たないゲームは `buildWorld` に `g34` が渡されず、これまでと完全に同じ陸地・同じ結果。保存は削除・書き換えしない。
- 地形ハッシュ・Stage 31〜33の地形編集は不変(地形は読み取りのみで、世界が配列を複製する)。

## 画面
追加した陸地は砂色のマス(島の拡大は濃い砂色、埋め立ては薄い砂色)で描かれ、年ごとの埋め立てはイベント欄に「首都・副首都の埋め立てでNマス(約Nkm²)」と出る。

## 既知の制限
- 島の拡大の判定は5km格子上の連結成分で行う。実際の島の面積(`IsletCell.areaKm2`)が30km²未満でも格子上で2マス以上なら拡大しない(格子の面積が既に50km²以上)。
- 島に置いた座席の人口上限(`capPop`)は元の島の面積のままで、拡大では増やさない。
- ポテンシャル計算(`potential17`)の地形メモは地形オブジェクト単位で、埋め立てでは更新しない(数マス分の海岸距離の差のみ)。
