# Stage 18: 都市名・元号選択UI・海路/空路重視・海側による順位補正 (Issue #38)

## 1. 都市名
原因: 地図の底の層(`renderer.ts drawCities`)が、都市データ(`terrain.cities`: Stage 17 までの追加都市を含む)の全点に丸と名前を付けていた。関東の川崎・川口・船橋などが最初から名前付きで出ていたのはこの層。
対処: Stage 17 の新規ゲームでは底の層は**県庁所在地49だけ**を描く(`capitalsOnly`)。データは削除していない。旧ゲーム(`sim.pot17` なし)は従来どおり全都市を描く。成長して表示条件(人口7万人かつ出発時の1.6倍、5万人未満で名前を外す。Stage 17と同じ。関東も地方も同じ条件)を満たした場所は、道路の層(`roads.ts drawCityCircles`)が丸と**名前**を描く。住民・経済は表示と無関係に残る。

## 2. 元号選択UI
- 最初の元号: 以前の `<select>` をやめ、大きな2つのタブ「道路系」「鉄道系」と、1候補1ボタン(最小高さ48px、2列)。選択中は黄色の枠と✔、上に「選択中: 名前(グループ・方針)」。
- 改元の画面: 同じタブ。候補ごとに全幅の大きなボタン(`◯◯にする`)。画面の先頭に「現在の元号」。
- 分類(`kaigen.ts eraGroup`): 実際の効果(1950〜2100年の鉄道整備意欲 `railBuild` の平均)で決める。鉄道重視 0.67 → 鉄道系。均衡 0.38・道路重視 0.17・空路重視 0.31・海路重視 0.33 → 道路系。判断: 空路・海路は均衡より鉄道を建てず、Stage 18 では新線・高速化をさらに抑えるので、道路側に置いた(鉄道系は1945年の候補14のうち3つ)。元号名・候補・効果・改元制度は変更していない。

## 3. 海路重視・空路重視(`policy18.ts`、Stage 18 の新規ゲーム `pot17.c18` のみ)
- 水底・湖底トンネルは原則新規建設しない。例外は、代替のフェリーの混雑が容量の200%以上、海峡幅25km以下、前回の例外から25年以上のときだけ(`【例外】`と明記)。技術条件(3倍・3倍・半額・半工期)は不変。
- 鉄道: 新線の優先度は1/3、高速化は計画しない、電化・複線化は1/2、政策の幹線高速化は止める。既存の鉄道は維持。
- 港・空港: 海路重視は港の意欲1.5倍・空港0.25倍(空港を作る人口の条件は2倍)。空路重視は逆。港・空港を縮小・閉鎖する条件は政策の影響を受けない(政策だけで消えない)。
測定(シード7、〜1989年。均衡 / 空路 / 海路):
| | 均衡 | 空路重視 | 海路重視 |
| --- | --- | --- | --- |
| 1989年までに開通した水底・湖底トンネル | 32 | 2 | 2 |
| 高速鉄道 km (2000年) | 1022 | 171 | 95 |
| 鉄道 km (2000年) | 7626 | 7210 | 7156 |
| 港の貨物量 / 規模合計 | 305,729 / 117 | 270,558 / 119 | 443,862 / 140 |
| 空港の旅客 / 国内航空路線 | 1,122,348 / 128 | 1,647,237 / 183 | 1,099,221 / 112 |
| フェリー | 49 | 56 | 60 |
政策は元号ごとなので、1989年以降の元号が別の方針なら、そのあとはその方針で建設される(テストは1989年まで)。

## 4. 日本海側・太平洋側による順位補正
順序: Stage 17 の順位(固定部分+ランダム部分)を先に確定 → 元号の復興方針の海側に該当する府県を、ランダム部分の中だけで2つ上げる(一極集中は17〜49位、地方分散は11〜49位。固定順位は動かさない)。該当府県を元のランダム順位の順に処理し、それぞれその時点の順位から2つ上へ挿入する(範囲の先頭が上限。先に処理した該当府県より上には行かない)。他の府県は後ろへ動く。常に1〜49位の順列。同じシード・政策なら同じ結果。補正後の順位から Stage 17 の重みを計算する(合計49のまま)。改元でも同じ規則で再割当され、重みは年7%ずつ新順位へ近づく(人口は瞬間移動しない)。
海側の判定(`potential17.ts coastCounts/coastSideOf`): 地形の実際の海岸線で、海に面した陸セルを日本海側(`recon.ts seaClass`の日本海)・太平洋側(太平洋・瀬戸内海・東シナ海)に数える。海岸セルが15未満は内陸(側なし)。片側が65%以上ならその側。両側の海に面し65%に届かない府県(山口・福岡・長崎・北海道の南西など)は側なし。瀬戸内海の府県は太平洋側。オホーツク海と湖は数えない。県域は種から生成した領域なので、小さい府県(山形・東京・大阪)は海岸セルが少なく側なし、奈良の細い部分は太平洋側と出る(地図の限界)。
既存の復興方針の効果(成長・予算・路線の優先・幹線の高速化)は変更していない。順位補正の効果は重みの差(2つ上げても1割未満)にとどまり、二重計上にならない。
例(東京首都・大阪副首都・東京皇居、一極集中、シード7、順位 前→後): 日本海側重視 — 福井22→20 秋田28→26 富山37→35 新潟40→38 鳥取41→39 島根44→42 石川45→43(ほかの府県は1〜2つ下がる)。太平洋側重視 — 三重23→21 岡山24→22 愛媛25→23 静岡30→28 香川32→30 愛知34→32 岩手35→33 高知36→34。地方分散・日本海側重視 — 福井13→11 富山15→13 秋田30→28 島根32→30 新潟41→39 石川43→41 鳥取44→42。
