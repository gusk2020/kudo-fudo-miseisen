# Stage 35: 遷都の統合と完全自動運転

実装: `src/sim/event2200.ts`(`slotsPassed`/`nextYear2200`/`unattended`/`skip2200`)、`src/sim/engine.ts`(境界での分岐)、`src/ui/e2200.ts`・`src/ui/app.ts`(遷都ウィザード)。

## 固定周期(ユーザー確定仕様)
- 遷都年 = **そのゲームの開始年 + 150年 × n**(n = 1, 2, 3, …)。固定の 2100 年・2200 年を全ゲーム共通の起点にはしない。例: 1950年開始 → 2100・2250・2400、2000年開始 → 2150・2300・2450、2050年開始 → 2200・2350・2500。
- ゲームは作られる時に最初の境界を `relocFirst`(= 開始年 + 150)として記録する。保存・読込・遷都をまたいでも開始年と起点は変わらない(遷都しても `startYear`/`relocFirst` は不変で、次の枠だけが進む)。
- 境界の枠は「開いた遷都 + スキップした境界」で数える。一時停止・再開・保存・復元で周期は動かない。
- 起点が記録されていない旧セーブは、読込時に**そのゲーム自身の履歴**から決める(固定の年は使わない): 遷都の履歴があれば最初の遷都の予定年を起点にして今までのリズムを保つ。履歴がなければ開始年 + 150 を起点にし、すでに過ぎた境界は「スキップ済み」として記録する(あとから遷都を出さない)。
- 以前の版で「新しいゲームは 2100、旧ゲームは 2200」としていた扱いと `RELOC_FIRST` 定数は廃止した(`relocFirstOf(開始年)` に置き換え)。

## 手動運転: 遷都ウィザード(4段階)
1. 元号・方針(元号は一度でも使ったものは出ない)
2. 首都・副首都・皇居(首都と副首都は別の府県、皇居は重複可。地図配置は Stage 32 と同じ)
3. 国道0号(遷都の道路。コードベースの既存名称。作らない選択も可)
4. 最終確認 → **確定して再開**

- 各段階に戻る(‹ 戻る)がある。段階1・2は下書き(`e22`)を保持する。
- 座席の「これで決定」で選択が適用される(国道0号は新しい座席の間に引くため)。**適用前にゲームのスナップショットを取り**(メモリと IndexedDB の別キー `…:relocsnap`、既存セーブは書き換えない)、国道0号の段階で「戻る」を押すとスナップショットを戻して座席の段階に帰る。下書きは残る。
- 上部の情報行は遷都中は非表示(Stage 31 の挙動のまま)。
- 確定(`確定して再開`)までは時間が進まない(`waiting2200`)。確定すると保存し、遷都直後のチェックポイントを取る。
- 途中保存・復元: 座席を適用する前(段階1・2)で保存して読み込むと、遷都は開いたまま最初の段階から。適用後(国道0号・最終確認)は国道0号の段階から再開し、時間は止まったまま。スナップショットがあれば戻ることもできる。
- Stage 34: 座席が決まる時に世界を作り直し、新しい座席の島を拡大する(`sim.rec34` に追記)。旧座席の埋め立ては止まり、埋めた土地は残り、新しい座席の予算は0から始まる。

## 完全自動運転: スキップ
- 完全自動 = 方針モード「常に自動」(`auto`)のみ。「放置中のみ自動」(半自動)、放置中、速度倍率(×1/×5/×20)は完全自動ではなく、従来どおり遷都で止まる。
- 境界に来ると、遷都・改元・座席変更・国道0号・ウィザードをまるごと見送り、**止まらずに進む**。元号・首都・副首都・皇居・道路・埋め立ての予算は一切変えない。年表に「完全自動運転のため遷都・改元は行わなかった」を記録する。
- スキップした境界は `sim.relocSkipped`(予定年の一覧)に残す。手動に戻しても**過去の遷都は行わず**、次の固定境界まで待つ。年をまたいで複数の境界を一度に通り過ぎても、順に一度ずつスキップするだけ。
- 同じ境界で二重に開かない: スキップ／開始のどちらでも次の予定年が 150 年先になる。保存・復元しても `due2200` は保存状態から決まるので誤発火しない。
- 遷都が開いている間(ウィザード中)に完全自動へ切り替えても、選択は捨てず、世界も変えない。その遷都は手動で終えるまで待つ。以後の境界から自動でスキップする。

## 既知の制限
- ウィザードの「戻る」は国道0号の段階から座席の段階への巻き戻しにスナップショットを使う。スナップショットを作った後にページを再読込した場合、保存キーから読み戻す。キーが無い／別の遷都のものなら戻れず、案内を出す。
- 完全自動中の改元(通常の元号の入れ替え)は、遷都とは別のタイマーで従来どおり行われる。
