# Stage 22: 一覧窓・外洋/離島航路・実海岸線・2200年遷都・都市名の削減

## 1. 府県・元号の一覧窓(`src/ui/radioWin.ts`)
- 地図の上に重ねる黒背景・白文字の窓。縦1列、窓の中だけがスクロール。名前の左に ○(未選択)/●(選択)。
- 選んでも閉じない。「閉じる」ボタンと窓の外のタップで閉じる。`<body>` 直下(最前面)に置くので下部ドックに隠れない。
- 府県: 北海道→沖縄、地方ブロックの見出しの下に49府県(ゲーム内の49府県・ブロック分類そのまま)。首都/副首都/皇居のタブで直接開く。「地図で選ぶ」(窓の下)→ 地図選択 →「戻る」で一覧へ。
- 元号(最初の元号): 同じ窓。輸送方針の見出しの下に候補、名前の直下にその元号固有の条件だけ。
- 改元時(ゲーム中)の元号シートは従来どおり(候補を押すと即決定)。2200年のイベントは同じ ○/● 方式。

## 2. 外洋航路・離島航路(`src/sim/sea22.ts`、新しいゲームのみ `sim.sea22`)
- 外洋航路: 港のある都市(沿岸の県庁所在地・人口10万以上・島の拠点)どうし。距離は海の上の距離(3×3セルの粗い海の格子でダイクストラ。東京〜新潟は本州を回る)。両端の人口・距離、陸路に対する短縮(陸塊が違えば加点)で評価。1960年から、政策に応じて毎年開設(海路重視: 年3・上限34、均衡: 年2・22、道路/鉄道: 年1・16、空路: 年1・12、空路重視は600km超の旅客を弱める)。使われない年が続くと休止(海路重視は2倍待つ)、需要・政策で再開。国外航路はつくらない。
- 離島航路: 住民のいる島(islets.json の `pop`: 概数)は、陸塊の違う最寄りの港(海の距離)へ1本、同じ群の最寄りの有人島へ1本。人口の多い島から年に数本(政策で変化)。収支によらず維持(休止・閉鎖の審査の対象外)。住民の少ない島は1965年以降。
- 航路はネットワークのフェリー辺で、需要モデルの移動を運ぶ。長さは海の距離。描画は海上の経路(seaPath)で陸を横切らない(テストで確認)。遠景では休止中と小さな航路を省略。

## 3. 地図(実海岸線)
- データ: 地球地図日本(国土地理院、1:100万)。dataofjapan/land の japan.geojson を `tools/build_coast22.py` で簡略化。表示用 `src/data/coast-gmj.json`(936ポリゴン・約2万点)と、各島の輪郭(`islets.json` の `shape`)。出典: 地球地図日本(国土地理院)。利用条件: 国土地理院コンテンツ利用規約に従い出典を明記(dataofjapan/land の README も同旨: 非営利は出典明記、営利は出典明記と利用報告)。
- 実在地図の画面では本州・北海道・四国・九州と全ての島をこの海岸線で描く(1回だけ作って再利用、線は1px)。地形図モードの陰影は従来の5kmグリッドのまま。
- 新しいゲーム(`sim.isl22`)の世界では、島の陸セルを実際の輪郭から作る(輪郭の内側のセル+中心のセル)。南鳥島・沖ノ鳥島を追加。Stage 20 のゲーム(`isl20` のみ)は従来の楕円のまま(セーブ互換)。
- 輪郭が対応しない島(多楽島・勇留島・久賀島・上島(天草: データ上は下島と一体))は輪郭なし。表示は点、5kmグリッドの陸は楕円の大きさ。小さすぎる島は点で示す(拡大しない)。タップの当たり判定は表示とは別(指の太さ)。
- 領有: 島の `claim` は事実のみ(沖ノ鳥島も追記)。ゲーム内の府県は仮の割り当て。

## 4. 2200年の遷都と復興(`src/sim/event2200.ts`、`sim.e2200`)
- 2200年以降の最初の年境界で一度だけ。時間は止まり、選択を待つ(放置設定=自動では現状維持で続行)。高速進行でまたいでも次の年境界で必ず発火。保存され再発火しない。
- 首都・副首都・皇居: 府県一覧または地図の点(新しい県庁所在地、`M22-<府県>`)。旧所在地の都市・道路・住民は残り、新しい都市は旧県庁所在地から少しだけ人を受け取る(作らない・消さない)。役割の質量(roles)は変えず、発展順位は新しい拠点で引き直され、年7%で漸進。
- 元号: 1912年(大正改元)に大正と並んで示された候補(天興・興化・永安・乾徳・昭徳。大正は既に使われたので除外)。読みつき。方針は元号と切り離す。
- 復興方針: 交通(道路/鉄道/海路/空路/均衡)、地域(日本海側/太平洋側/中立)、都市配置(一極集中/地方分散)を自由に組み合わせ。復興方針の強さは2200年から改めて減衰(`recon.since`)。
- 国道0号: 新首都〜新副首都を手描き(双方向)。経路は既存の道路(開いている道・旧道・廃道)のセルを優先して探索し、同じ辺を共有して国道1号と重複指定(二重の道は作らない)。閉鎖・廃道の区間は復旧してから使い、隙間だけ新設。沿道の県庁所在地は経由・取付路(Stage 21)。工事費相当(新設1/km・復旧0.35/km)は記録し、開通の儀として一括で供用。国道1号は上書きしない。

## 5. 都市名
- 衛星都市名の上限 10/24/60 → 7/18/45。県庁所在地の名前は、中間の縮尺では重要度順(首都・副首都・皇居の府県、次に人口)に25まで、衝突なく(0.85以上で全49)。都市・人口・交通は全て従来どおりシミュレーション。
