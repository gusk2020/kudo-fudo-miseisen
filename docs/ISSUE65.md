# Issue #65: 長期人口配分の感度（stage24「福岡 10倍」）の調査

状態: 調査済み。**所有者の承認（2026-11-12、選択1）により `stage24` の基準を、意味のある不変条件を複数シードで検証する方式へ置き換えた**（下の「置換」）。長期配分の離散的な分岐そのものは**未解決のまま**（置換は分岐の解消ではない）。

## 測定（すべて固定シード・`run14`・2230年、`tests/study/lib14` 経由）
1. 比率 move/keep の3シード（修正前→修正後）: シード5 11.55→9.93、11: 30.59→27.43、23: 14.40→31.91。人口総数は約40Mで不変。
2. 分子（遷都後の福岡県シェア）は安定: 0.1001〜0.1166（全測定の範囲、平均 ≈0.109、変動 ±8%）。分母 keep（遷都なしの福岡のシェア）は 0.0033〜0.0113（3.4倍の幅）。比率の変動はほぼ分母による。
3. 陸上の線の品質を 78, 79, 80(既定), 81, 82, 92 に変えたシード5の keep:
   - 78, 79, 80 → 福岡 0.01131／東京 0.3167／大阪 0.1878（**3つとも完全に同じ状態**）
   - 81, 82 → 福岡 0.00363／東京 0.3407／大阪 0.1976（**2つとも完全に同じ状態**）
   つまり連続的なノイズではなく、**二つの離散的な分岐**のどちらかに落ちる。品質80〜81の間に境目がある（品質に直接の閾値は見つからず、`edgeSpeed` は品質に連続）。
4. 分岐の現れ方（シード5、品質79 対 81、遷都なし）: 1990年までは県別シェアが**完全に一致**。2050年に差が出始める（兵庫 +63bp、神奈川 −55bp、愛知 +24bp、福岡 −21bp）。2150年: 東京 +206bp、神奈川 +149bp、兵庫 +124bp、山口(JP-34相当) −113bp。2230年: 東京 0.3167 対 0.3407。差は福岡に限らず、大都市圏の配分全体に広がる。

## 読み取り（確実さを区別して）
- **確実**: (a) 福岡の比率の変動は主に分母（遷都しないときの福岡の小さな自然シェア、0.3〜1.1%）の変動による。(b) 品質のわずかな違い（0.2%の速度差）で、1990〜2050年の間に国全体の配分が二つの分岐に分かれる。人口総数は保存される。
- **確実ではない（未特定）**: 分岐を起こす具体的な離散的決定（候補プロジェクトの選択順位の入れ替え、`city17` の保持県・候補の交代、`potential17` の上限と零和の組み合わせのどれか）。1990〜2050年の間の月次の差分追跡が次の手順。
- 「経路距離 83.5→93.1km」だけが原因とは言えない（品質を上げても距離は同じで結果が変わる）。

## 評価（モデルの問題か、指標の問題か）
- **指標の問題（確実）**: 比率 move/keep は、ばらつきの大きい小さな分母で割るため、模型の健全さを測る指標として不安定。単一シードの 10倍という値は、仕様（新首都が確実に伸びる）の十分条件でも必要条件でもない。
- **モデルの性質（確実）**: 長期の人口配分は、小さな交通条件の差で離散的に分岐する（カオス的）。これは今回の海峡修正が作ったものではなく、近接した選択肢の入れ替えで以前からありうる性質で、測定で見えたのが今回。
- 修正すべきシミュレーション上の**不具合は今回の調査では特定できていない**。したがって福岡の優遇・品質の値合わせ・補正係数は入れていない。

## 提案（自動適用しない・所有者の承認が要る）
意味のある不変条件を、シードに依らない形で検査する案:
1. 遷都した県のシェアが大きい: `share(move, 新首都) > 0.08`（観測 0.100〜0.117）かつ遷都しない場合の 5倍超（観測 3シードで 9.9〜32）。
2. 旧首都は減る: `share(move, 東京) < share(keep, 東京)`（既存の検査と同じ）。
3. 人口総数が保存される（既存の検査と同じ、1%以内）。
4. 複数シード（例 3〜5）で上記が成り立つこと。
これは基準の変更なので、承認なしには適用しない。選択肢B: 分岐を起こす離散的決定を特定し、モデル側で安定化する（別の調査）。
