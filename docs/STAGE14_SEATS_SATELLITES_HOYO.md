# Stage 14 (Issue #35): 首都・副首都の順位、衛星都市、日本海側重視、豊予海峡、都市の丸

Stage 12 以降の新規ゲーム(年表の第1期から)だけに働く。`sim.seats14` が立つ。既存セーブには付かず、Stage 1〜13 の挙動はそのまま。

## 1. 首都・副首都は単独都市人口の上位2つ (`src/sim/seats14.ts`)
- 規則: 選んだ首都・副首都の単独人口が全国の1位・2位になる。他の都市は超えない(産業・物流・貿易・観光の機能は人口とは別なので超えてよい)。
- 人為的な規則である(自然に起きる現象ではなく、ゲーム側の取り決め)。実装は「郊外化」: 座席を超えかけた都市の人口を、座席の隣接府県の都市へ移す。総人口は厳密に保存する(移した分は他で増えた分と一致)。その後、自然増減の全国曲線(natRate)に合わせて全体を再スケールする。
- 副作用の抑え: 受け皿が1都市に集中すると膨らむので、`SUBURB_MAX_RATIO`・成長上限・人口^0.4 の重みで分散させた。
- アクセス・追い風の項は新規ゲームでは平均を引いて、総人口を押し上げないようにした。

## 2. 衛星都市と都市圏
衛星は座席の隣接府県の都市が、通勤・鉄道・道路・産業で育つ。府県境は越える。地形係数(平野1.5・丘1・高地0.5)で面積が決まる。中心都市の肥大は上記で抑える。東京圏は2000年に5市以上・2〜3府県。大阪圏は神戸・京都・和歌山・大津が属す(1つの都市は1つの圏にだけ属す: 二重計上0)。

## 3. 日本海側重視を効かせる
原因調査: 以前の方針は初期網・計画・予算・人口移動・港・産業のどれにも十分な力で届いていなかった。`RECON_BOOST = 2.5` で4項(成長・産業・予算配分・計画優先)を強め、海岸側は実際の海(`coastSide`)、集中/分散は座席への近さで決める。太平洋側は禁止していない。

## 4. 豊予海峡(九州〜四国)
原因は複合: 島間の連絡候補が、人口の少ない両岸では出ない(候補不足)、港が孤立した陸塊に置かれていた(接続不良)、アクセス道路が休止して端が網から切れていた。直した点: 主要4島の最狭海峡を必ず航路候補にする(`mainStraitLinks`)、港は島の主陸塊に置く、`ensureAccess`/`reviveAccess` で両端を網につなぐ、【島間】計画は優先する。
結果: 水底トンネル3倍時に1976〜77年開通(通常技術では2005年)。両端から100以上の拠点へ到達でき、交通量(through+local)>0、年表に「海峡連絡が開通…(海底トンネル)」が載る。水中トンネルの仕様(技術3倍速・距離3倍・費用/期間は半分相当・他のトンネルは据え置き)は不変。

## 5. 都市の丸 (`src/render/cityCircles.ts`)
東京の丸が道路の束に隠れて消えていた。丸を最上層(`cityTop`)に出し、座席2つ(金の輪)・都市圏の核・座席の圏にある15万人以上の衛星・全国最大の都市を、どの縮尺でも必ず描く。既存の丸の意味(面積=都市圏、緑/赤/灰)は同じで、▲▼は戻していない。地図帳に座席の欄(`#eco-seats`)を追加。

## 8. 残っている制約
- 島の首都(札幌など)では、同じ島に圏の構成員が少なく、衛星の育ち方は本州より小さい。
- 佐渡の大きさは既存の役割スケールに由来し、今回は変えていない。
- 太平洋側重視+集中では日本海側の人口割合が2100年に約1%まで下がる(禁止はしていない結果)。
- 地形: 関東に尾根を置いた世界(シード7)では、東京圏の面積が2000年に 16,500→9,775 km²、府県数 9→6、圏の人口 35.4M→32.4M に減り(1980年も 13,500→10,125 km²)、衛星の数も減る。順位(東京1位・大阪2位)と総人口(59.0M)は変わらない。尾根が圏を狭めるが座席の順位は保つ。
