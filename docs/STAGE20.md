# Stage 20: 設定欄の整理 / 地図で選んだ点を県庁所在地に / 離島の追加 / 小さな島の拠点

## A. 設定欄
- 4つのタブ(元号・首都・副首都・皇居)は維持。同じ見出し・ボタンの重複を除去。選択中はゲーム標準の青(`#1f6fd1`)。
- 元号の一覧は輸送方針ごとの見出し(道路重視 / 鉄道・公共交通重視 / 海路重視 / 空路重視 / 均衡)で1回だけ説明し、各候補には自分の条件(日本海側・太平洋側・一極集中・地方分散)だけを表示。初期選択と改元で同じ表示。
- Stage 18/19 の方針・沿岸順位補正・元号の仕組みは変更なし。

## B. 地図で選んだ点 → 県庁所在地
- 首都・副首都・皇居を地図で決めると、その点が **その府県の新しい県庁所在地** になる(`src/sim/seatmove20.ts`)。
- 名前は **最寄りの実在地名 + 市**(`src/core/gazetteer.ts`)。「市市」にはしない。ゲーム内に同名の都市があるときは、まだ都市でない最寄りの地名を使う。25km以内にゲーム内の都市があればその都市が県庁所在地になる(新しい都市は作らない)。
- 旧県庁所在地は普通の都市として残り(`former`)、住民は急にいなくならない。開始時の「9割を県庁所在地へ集める」処理から外し、年次の都市配分(`settleCities`)だけで徐々に動く。
- 人口は作らない: 新都市の開始人口は旧県庁所在地の1950年規模から分けた分(1%、300〜2万人)で、府県の合計は不変(テストで確認)。
- 1府県に県庁所在地は1つ。複数の役割が同じ府県を動かすときは 首都 > 副首都 > 皇居 の順(`SeatMove.by` に動かした役割を記録)。役割の座標(`capitalPos`等)と県庁所在地の座標は別に保持。
- ゲームは `sim.moves20` に移転を記録し、読み込み時は同じ世界を作り直す。保存と世界が合わなければ読み込みを拒否(`validateSimAgainstWorld`)。旧セーブ(`moves20`なし)は従来どおり(座標だけが違う)。

## C. 離島
- `src/data/islets.json`: 101の島(伊豆諸島・小笠原・硫黄島・大隅・トカラ・奄美・沖縄・宮古・八重山・尖閣・大東・竹島・北方四島・歯舞・日本海・瀬戸内・北海道の島)。位置・面積・最高点・長さ/幅/向きは概数で、海岸線そのものではなく同じ大きさの楕円。南鳥島・沖ノ鳥島は範囲外としてこの版では入れていない。
- 世界側のパッチ(`src/sim/islands20.ts`、`withIslets`)。地形ハッシュは変えない。5kmグリッドが東西南北に足りないため、同じ格子のまま範囲を広げる(旧セルは同じ位置のまま)。島ごとに固有の島番号を与えるので、道路では結べず航路で結ばれる。既に陸のセルにある島は二重登録せず「既存」扱い。
- 領有: `claim` に事実のみ(例「ロシアが実効支配し、日本が領有を主張している(領有権に争いがある)」)。ゲーム内の府県は **仮の割り当て** であって現実の領有判断ではない。
- 描画: 実寸の楕円(最小で指の太さ)。領有に争いのある島は縁を茶色に。

## D. 小さな島の拠点
- 地図選択のタップは指の太さ(24px相当)の当たり判定。海をタップしたとき、範囲内で最も近い島を選ぶ(近い島同士は最寄り優先)。陸のタップでは8px以内の島だけを優先。確認前に名前・最寄りの地名・領有の事実を表示し、決定/取り消し、仮の十字マーカーを出す。
- 島の収容人口は **面積 × 2,500人/km²**(`cap20.ts`)。超えた分は同じ府県の他の都市へ人単位で戻す(人は増減しない)。シミュレーションの最小都市人口は2,000(モデルの下限)。
- 収容が100万に満たない島の拠点は、全国の都市順位を決める首都・副首都ルール(`applySeatOrder`)の対象外。旧県庁所在地が府県の都市人口を持ち続け(`prefHolders`)、新しい都市は徐々に増える。
- 離島との航路: 離島を含む世界ではフェリーの最大距離を 760km → 1,300km(`maxFerryKm`)。小笠原・硫黄島は東京から約1,000〜1,200km。

## E. 国道1号
- 起点・終点は(移転後の)県庁所在地の都市。離島の都市まで航路で結ばれる(ユニット・E2Eで硫黄島・魚釣島・竹島・択捉島を確認)。

## 制約と未確認
- 実機(Pixel 7a)での操作感・体感性能は未確認。
- 島の位置・形は概数。沿岸の複雑な島(択捉・国後など)の形は楕円で近似。
- 島ごとの水・港・空港の適性は面積・標高だけで、個別の地形判定はしていない。
